#### **任务2.2：预测误差影响的理论模型** 🔴 高优先级

**目的**：推导预测误差ε对AoI的影响

**内容**：
```markdown
## 预测误差对AoI的理论影响

**模型假设**：
- 预测误差：ε ∈ [0, 1]（0=完美预测，1=随机猜测）
- 真实触发时刻：t_real
- 预测触发时刻：t_pred = t_real ± δ，其中 δ ~ N(0, ε·T_check)

**AoI增量分析**：
ΔA(ε) = E[A_with_error] - E[A_perfect]
       = ... (推导)
       ≈ α · ε² · T_check

**结论**：
1. AoI增量与预测误差的平方成正比
2. ε < 0.1时，AoI增加 < 5%（可容忍）
3. ε > 0.5时，预测优势消失
```

**输出文档**：`04.1_附录C_预测误差理论分析.md`

**实验验证**（等仿真后）：

#### **任务2.3：公平性指标设计** 🟡 中优先级

**目的**：设计Jain公平性指数的计算方法

**内容**：
```markdown
## 公平性分析框架

### Jain公平性指数定义

对于N辆车的AoI：{A₁, A₂, ..., Aₙ}

JFI = (Σ Aᵢ)² / (N · Σ Aᵢ²)

**性质**：
- JFI ∈ [1/N, 1]
- JFI = 1：完全公平（所有车AoI相同）
- JFI → 1/N：完全不公平（一辆车极优，其他极差）

### 公平性权衡分析

**问题**：高速车辆触发频率高，是否会占用更多资源？

**分析**：
1. 高速车：v=40m/s，触发频率=10Hz
2. 低速车：v=10m/s，触发频率=2.5Hz
3. 资源占用比 = 4:1

**设计选择**：
- 方案A：**按需分配**（触发多的车获得更多资源）- 本文采用
  - 优点：符合实际需求，AoI最优
  - 缺点：可能不公平
- 方案B：**均匀分配**（每辆车资源相同）
  - 优点：公平
  - 缺点：高速车AoI恶化

**本文立场**：
采用方案A（按需分配），并论证其合理性：
"高速车辆需要更频繁的状态更新以保证安全，资源的不均匀分配
是系统需求驱动的，而非算法缺陷。"
```

**输出文档**：`07.1_附录D_公平性分析.md`

**实验验证**（等仿真后）：
- 计算不同场景下的JFI
- 对比PAPO与基线的公平性

#### **任务2.4：算法复杂度详细分析** 🟢 低优先级

**目的**：量化各算法的时间/空间复杂度

**内容**：
```markdown
## 算法复杂度汇总表

| 算法模块 | 时间复杂度 | 空间复杂度 | 说明 |
|---------|-----------|-----------|------|
| **CPA（集中式相位分配）** | O(M·N) | O(N) | 初始化一次 |
| **DPA（分布式相位调整）** | O(k log k) | O(k) | 每次车辆加入 |
| **Lyapunov卸载决策** | O(N'·M) | O(N) | 每时隙，N'为有任务车辆数 |
| **资源分配（凸优化）** | O(N'³) | O(N'²) | KKT求解 |
| **任务预测（GRU）** | O(N·H²·L) | O(N·H·L) | H=隐层，L=序列长 |
| **总体（单时隙）** | O(N·M + N'³) | O(N) | 通常N'³占主导 |

**可扩展性分析**：
- N=100, M=10, N'≈30：单时隙 ~0.1秒（CPU）
- 满足实时性要求（T_check=100ms）
```
