# 03 算法设计：相位对齐调度

本文档详细介绍相位对齐调度算法的设计与实现。

---

## 1. 问题背景

### 1.1 同步拥塞问题

**场景描述**：

当多辆车的检查周期相同（如100ms）且相位对齐时，会在固定时刻产生流量峰值。

```
未对齐时的流量模式：

流量
 ↑
 │████            ████            ████
 │████            ████            ████
 │████            ████            ████
 └─────┬──────────┬──────────────┬─────→ 时间
       0ms       100ms         200ms

峰值时刻所有车辆同时传输，RSU拥塞！
```

### 1.2 相位对齐的目标

通过为不同车辆分配不同的相位偏移，使流量在时间上均匀分布。

```
相位对齐后的流量模式：

流量
 ↑
 │██  ██  ██  ██  ██  ██  ██  ██  ██
 │██  ██  ██  ██  ██  ██  ██  ██  ██
 └──┬───┬───┬───┬───┬───┬───┬───┬──→ 时间
    0  20  40  60  80 100 120 140

流量均匀分布，避免拥塞！
```

---

## 2. 相位分配算法设计

### 2.1 算法概述

我们设计两种相位分配算法：

| 算法 | 适用场景 | 执行时机 |
|------|----------|----------|
| **CPA**（集中式） | 系统初始化 | 一次性 |
| **DPA**（分布式） | 车辆动态加入/离开 | 按需 |

### 2.2 算法1：集中式相位分配（CPA）

**算法名称**：Centralized Phase Allocation (CPA)

**执行时机**：系统启动时，或定期重新分配

**算法描述**：

```
算法 CPA：集中式相位分配
════════════════════════════════════════════════════════════════

输入：
  - 车辆集合 N = {1, 2, ..., n}
  - RSU集合 M = {1, 2, ..., m}
  - 检查周期 T_check
  - 车辆-RSU覆盖关系 Coverage(i) for each vehicle i

输出：
  - 每辆车的相位偏移 φ = {φ_1, φ_2, ..., φ_n}

════════════════════════════════════════════════════════════════

步骤：

1. 初始化已分配集合 Assigned = ∅

2. FOR each RSU m ∈ M:

   2.1 获取该RSU覆盖范围内的未分配车辆：
       N_m = {i ∈ N : m ∈ Coverage(i) AND i ∉ Assigned}

   2.2 IF |N_m| = 0:
       CONTINUE

   2.3 计算相位间隔：
       Δφ_m = T_check / |N_m|

   2.4 为每辆车分配相位：
       FOR j = 1 to |N_m|:
           φ_{N_m[j]} = (j - 1) × Δφ_m
           Assigned = Assigned ∪ {N_m[j]}

3. RETURN φ

════════════════════════════════════════════════════════════════
```

**数学表达**：

对于RSU $m$ 覆盖的 $n_m$ 辆车，分配的相位为：

$$\phi_i^{(m)} = \frac{(i-1) \cdot T_{check}}{n_m}, \quad i = 1, 2, ..., n_m$$

**复杂度分析**：
- 时间复杂度：$O(M \cdot N)$
- 空间复杂度：$O(N)$

### 2.3 算法2：分布式相位调整（DPA）

**算法名称**：Distributed Phase Adjustment (DPA)

**执行时机**：车辆进入新的RSU覆盖区时

**算法描述**：

```
算法 DPA：分布式相位调整
════════════════════════════════════════════════════════════════

触发条件：新车辆 v_new 进入RSU m 的覆盖区

输入：
  - 新车辆 v_new
  - 当前RSU m
  - 已分配的相位集合 Φ_used = {φ_1, φ_2, ..., φ_k}
  - 检查周期 T_check

输出：
  - 新车辆的相位 φ_new

════════════════════════════════════════════════════════════════

步骤：

1. IF |Φ_used| = 0:
   φ_new = 0
   RETURN φ_new

2. 将已分配相位排序：
   Φ_sorted = SORT(Φ_used)

3. 计算相邻相位间的间隔：
   FOR i = 1 to |Φ_sorted|:
       IF i < |Φ_sorted|:
           gap[i] = Φ_sorted[i+1] - Φ_sorted[i]
       ELSE:
           // 处理环形边界
           gap[i] = (Φ_sorted[1] + T_check) - Φ_sorted[i]

4. 找到最大间隔：
   i_max = argmax(gap)

5. 新相位取最大间隔的中点：
   IF i_max < |Φ_sorted|:
       φ_new = (Φ_sorted[i_max] + Φ_sorted[i_max + 1]) / 2
   ELSE:
       φ_new = (Φ_sorted[i_max] + Φ_sorted[1] + T_check) / 2
       φ_new = φ_new mod T_check

6. RETURN φ_new

════════════════════════════════════════════════════════════════
```

**示例**：

```
当前已分配相位：Φ_used = {0ms, 30ms, 70ms}
T_check = 100ms

相邻间隔：
  gap[1] = 30 - 0 = 30ms
  gap[2] = 70 - 30 = 40ms
  gap[3] = (0 + 100) - 70 = 30ms

最大间隔：gap[2] = 40ms

新相位：φ_new = (30 + 70) / 2 = 50ms

更新后：Φ_used = {0ms, 30ms, 50ms, 70ms}
```

**复杂度分析**：
- 时间复杂度：$O(k \log k)$（排序）
- 空间复杂度：$O(k)$

## 3. Python代码实现

### 3.1 相位分配器类

```python
"""
相位对齐调度模块
文件：algorithms/phase_allocator.py
"""

import numpy as np
from typing import List, Dict, Optional, Tuple
from dataclasses import dataclass


@dataclass
class Vehicle:
    """车辆数据类"""
    id: int
    position: np.ndarray  # [x, y]
    speed: float


@dataclass
class RSU:
    """RSU数据类"""
    id: int
    position: np.ndarray  # [x, y]
    coverage_radius: float


class PhaseAllocator:
    """
    相位分配器

    实现集中式和分布式两种相位分配算法
    """

    def __init__(self, T_check: float = 0.1):
        """
        初始化相位分配器

        Args:
            T_check: 检查周期（秒），默认100ms
        """
        self.T_check = T_check
        self.phase_assignments: Dict[int, float] = {}  # vehicle_id -> phase

    def centralized_allocation(self,
                                vehicles: List[Vehicle],
                                rsus: List[RSU]) -> Dict[int, float]:
        """
        集中式相位分配（CPA算法）

        在系统初始化时调用，为所有车辆分配相位

        Args:
            vehicles: 车辆列表
            rsus: RSU列表

        Returns:
            phase_assignments: {vehicle_id: phase_offset}
        """
        assigned = set()  # 已分配的车辆ID
        self.phase_assignments = {}

        for rsu in rsus:
            # 获取该RSU覆盖范围内的未分配车辆
            covered_vehicles = [
                v for v in vehicles
                if self._is_covered(v, rsu) and v.id not in assigned
            ]

            n = len(covered_vehicles)
            if n == 0:
                continue

            # 均匀分配相位
            phase_interval = self.T_check / n

            for idx, vehicle in enumerate(covered_vehicles):
                phase = idx * phase_interval
                self.phase_assignments[vehicle.id] = phase
                assigned.add(vehicle.id)

        return self.phase_assignments.copy()

    def distributed_adjustment(self,
                                new_vehicle: Vehicle,
                                rsu: RSU,
                                existing_phases: List[float] = None) -> float:
        """
        分布式相位调整（DPA算法）

        当新车辆加入时调用

        Args:
            new_vehicle: 新加入的车辆
            rsu: 当前RSU
            existing_phases: 该RSU下已分配的相位列表（可选）

        Returns:
            new_phase: 新车辆的相位
        """
        # 如果未提供existing_phases，从当前分配中获取
        if existing_phases is None:
            existing_phases = list(self.phase_assignments.values())

        # 空集合情况
        if not existing_phases:
            self.phase_assignments[new_vehicle.id] = 0.0
            return 0.0

        # 排序现有相位
        sorted_phases = sorted(existing_phases)

        # 计算相邻相位间的间隔，包括环形边界
        gaps = []
        n = len(sorted_phases)

        for i in range(n):
            if i < n - 1:
                gap = sorted_phases[i + 1] - sorted_phases[i]
                midpoint = (sorted_phases[i] + sorted_phases[i + 1]) / 2
            else:
                # 环形边界：从最后一个到第一个（跨越T_check）
                gap = (sorted_phases[0] + self.T_check) - sorted_phases[i]
                midpoint = (sorted_phases[i] + sorted_phases[0] + self.T_check) / 2
                midpoint = midpoint % self.T_check

            gaps.append((gap, midpoint))

        # 找最大间隔的中点作为新相位
        max_gap, best_phase = max(gaps, key=lambda x: x[0])

        self.phase_assignments[new_vehicle.id] = best_phase
        return best_phase

    def remove_vehicle(self, vehicle_id: int):
        """
        移除车辆的相位分配

        Args:
            vehicle_id: 车辆ID
        """
        if vehicle_id in self.phase_assignments:
            del self.phase_assignments[vehicle_id]

    def get_transmission_time(self, vehicle_id: int, slot: int) -> float:
        """
        获取车辆在给定时隙的实际传输时刻

        Args:
            vehicle_id: 车辆ID
            slot: 时隙索引

        Returns:
            transmission_time: 传输时刻（秒）
        """
        base_time = slot * self.T_check
        phase = self.phase_assignments.get(vehicle_id, 0)
        return base_time + phase

    def get_phase(self, vehicle_id: int) -> float:
        """
        获取车辆的相位

        Args:
            vehicle_id: 车辆ID

        Returns:
            phase: 相位偏移
        """
        return self.phase_assignments.get(vehicle_id, 0)

    def get_all_phases(self) -> Dict[int, float]:
        """获取所有相位分配"""
        return self.phase_assignments.copy()

    def _is_covered(self, vehicle: Vehicle, rsu: RSU) -> bool:
        """
        检查车辆是否在RSU覆盖范围内

        Args:
            vehicle: 车辆
            rsu: RSU

        Returns:
            is_covered: 是否被覆盖
        """
        distance = np.linalg.norm(vehicle.position - rsu.position)
        return distance <= rsu.coverage_radius

    def analyze_distribution(self) -> Dict[str, float]:
        """
        分析当前相位分配的均匀性

        Returns:
            metrics: 分析指标
        """
        if len(self.phase_assignments) < 2:
            return {'uniformity': 1.0, 'max_gap': self.T_check, 'min_gap': self.T_check}

        phases = sorted(self.phase_assignments.values())
        n = len(phases)

        # 计算所有间隔
        gaps = []
        for i in range(n):
            if i < n - 1:
                gap = phases[i + 1] - phases[i]
            else:
                gap = (phases[0] + self.T_check) - phases[i]
            gaps.append(gap)

        # 理想间隔
        ideal_gap = self.T_check / n

        # 均匀性指标（1表示完全均匀）
        uniformity = 1 - np.std(gaps) / ideal_gap if ideal_gap > 0 else 1.0

        return {
            'uniformity': uniformity,
            'max_gap': max(gaps),
            'min_gap': min(gaps),
            'ideal_gap': ideal_gap,
            'num_vehicles': n
        }


# ============================================================
# 单元测试
# ============================================================

def test_phase_allocator():
    """测试相位分配器"""

    print("=" * 60)
    print("测试相位分配器")
    print("=" * 60)

    # 创建测试数据
    vehicles = [
        Vehicle(id=i, position=np.array([i * 100, 0]), speed=20)
        for i in range(5)
    ]

    rsus = [
        RSU(id=0, position=np.array([200, 0]), coverage_radius=300)
    ]

    # 测试集中式分配
    allocator = PhaseAllocator(T_check=0.1)
    phases = allocator.centralized_allocation(vehicles, rsus)

    print("\n1. 集中式分配结果：")
    for vid, phase in sorted(phases.items()):
        print(f"   车辆 {vid}: 相位 = {phase*1000:.1f} ms")

    # 分析均匀性
    metrics = allocator.analyze_distribution()
    print(f"\n   均匀性: {metrics['uniformity']:.3f}")
    print(f"   最大间隔: {metrics['max_gap']*1000:.1f} ms")
    print(f"   最小间隔: {metrics['min_gap']*1000:.1f} ms")

    # 测试分布式调整
    print("\n2. 分布式调整测试：")
    new_vehicle = Vehicle(id=10, position=np.array([150, 0]), speed=25)
    new_phase = allocator.distributed_adjustment(new_vehicle, rsus[0])
    print(f"   新车辆 10: 相位 = {new_phase*1000:.1f} ms")

    # 再次分析均匀性
    metrics = allocator.analyze_distribution()
    print(f"\n   更新后均匀性: {metrics['uniformity']:.3f}")

    print("\n" + "=" * 60)
    print("测试完成！")
    print("=" * 60)


if __name__ == "__main__":
    test_phase_allocator()
```

```python
    reduction = (max(traffic_before) - max(traffic_after_aggregated)) / max(traffic_before) * 100
    print(f"  峰值降低: {reduction:.1f}%")
```

## 4. 理论分析

### 4.1 峰值负载分析

**定理1（未对齐情况）**：

设有 $n$ 辆车，任务生成概率为 $p$，相位均为0。

则某时隙同时传输的车辆数 $N_{sync}$ 满足：

$$\mathbb{E}[N_{sync}] = np$$
$$\text{Var}[N_{sync}] = np(1-p)$$
$$\Pr[N_{sync} = n] = p^n \quad \text{（最坏情况）}$$

**定理2（对齐后情况）**：

采用均匀相位分配后，设细粒度时间片为 $\Delta t = T_{check}/n$。

在任一时间片内传输的车辆数 $N_{aligned}$ 满足：

$$\mathbb{E}[N_{aligned}] = p$$
$$\text{Var}[N_{aligned}] = p(1-p)/n$$

**峰值降低比例**：

$$\text{Reduction} = 1 - \frac{\mathbb{E}[N_{aligned}]}{\mathbb{E}[N_{sync}]} = 1 - \frac{1}{n}$$

### 4.2 均匀分配的最优性

**定理3**：

在所有车辆任务生成概率相同的情况下，均匀相位分配最小化期望峰值负载。

**证明思路**：

设 $n$ 辆车的相位为 $\phi_1, \phi_2, ..., \phi_n$。

期望峰值负载可表示为相位分布的函数。通过拉格朗日乘子法，可证明当相位均匀分布时达到最小。

### 4.3 DPA算法的竞争比分析

**定理4（DPA竞争比）**：DPA算法是**2-competitive**的，即对于任意车辆到达序列，DPA产生的最大相位间隔不超过最优解的2倍：

$$\frac{G_{max}^{DPA}}{G_{max}^*} \leq 2$$

**证明要点**：
1. DPA每次将新相位放在最大间隔中点，保证任意两个间隔比值 $\leq 2$
2. 由此可推导 $G_n^{DPA} \leq 2T/n$，而最优解 $G_n^* = T/n$
3. 竞争比紧致：存在输入序列使比值任意接近2

**详细证明**：请参见 [附录B：DPA竞争比证明](./03.1_附录B_DPA竞争比证明.md)

**实际意义**：
- 最坏情况下，DPA的峰值负载不超过最优解的2倍
- 在V2X动态场景中，这一保证使DPA成为可靠的在线算法选择

### 4.4 复杂度分析

| 算法 | 时间复杂度 | 空间复杂度 | 通信开销 |
|------|------------|------------|----------|
| CPA | $O(MN)$ | $O(N)$ | 集中式，需全局信息 |
| DPA | $O(k \log k)$ | $O(k)$ | 分布式，仅需局部信息 |

其中 $M$ 是RSU数量，$N$ 是车辆数量，$k$ 是单个RSU覆盖的车辆数。

## 5. 处理动态场景

### 5.1 车辆进入场景

当新车辆进入RSU覆盖区：

1. 调用DPA算法分配相位
2. 更新RSU的相位列表
3. 新车辆开始按分配相位传输

### 5.2 车辆离开场景

当车辆离开RSU覆盖区：

1. 从RSU的相位列表中移除该车辆
2. **不需要**重新分配其他车辆的相位（避免抖动）

### 5.3 RSU切换场景

当车辆从RSU_A切换到RSU_B：

1. 在RSU_A中移除该车辆
2. 在RSU_B中调用DPA为其分配新相位
3. 考虑切换延迟，预留足够时间

### 5.4 代码实现

```python
class DynamicPhaseManager:
    """
    动态相位管理器

    处理车辆进入、离开、切换RSU等动态场景
    """

    def __init__(self, T_check: float = 0.1):
        self.T_check = T_check
        self.rsu_phases: Dict[int, Dict[int, float]] = {}  # rsu_id -> {vehicle_id: phase}
        self.vehicle_rsu: Dict[int, int] = {}  # vehicle_id -> rsu_id

    def initialize_rsu(self, rsu_id: int):
        """初始化RSU的相位列表"""
        if rsu_id not in self.rsu_phases:
            self.rsu_phases[rsu_id] = {}

    def vehicle_enter(self, vehicle_id: int, rsu_id: int) -> float:
        """
        车辆进入RSU覆盖区

        Returns:
            allocated_phase: 分配的相位
        """
        self.initialize_rsu(rsu_id)

        existing_phases = list(self.rsu_phases[rsu_id].values())

        if not existing_phases:
            new_phase = 0.0
        else:
            # DPA算法
            sorted_phases = sorted(existing_phases)
            n = len(sorted_phases)

            # 找最大间隔
            max_gap = 0
            best_phase = 0

            for i in range(n):
                if i < n - 1:
                    gap = sorted_phases[i + 1] - sorted_phases[i]
                    mid = (sorted_phases[i] + sorted_phases[i + 1]) / 2
                else:
                    gap = (sorted_phases[0] + self.T_check) - sorted_phases[i]
                    mid = (sorted_phases[i] + sorted_phases[0] + self.T_check) / 2
                    mid = mid % self.T_check

                if gap > max_gap:
                    max_gap = gap
                    best_phase = mid

            new_phase = best_phase

        # 记录分配
        self.rsu_phases[rsu_id][vehicle_id] = new_phase
        self.vehicle_rsu[vehicle_id] = rsu_id

        return new_phase

    def vehicle_leave(self, vehicle_id: int):
        """车辆离开当前RSU"""
        if vehicle_id in self.vehicle_rsu:
            rsu_id = self.vehicle_rsu[vehicle_id]
            if rsu_id in self.rsu_phases:
                self.rsu_phases[rsu_id].pop(vehicle_id, None)
            del self.vehicle_rsu[vehicle_id]

    def vehicle_handover(self, vehicle_id: int, new_rsu_id: int) -> float:
        """
        车辆切换RSU

        Returns:
            new_phase: 在新RSU的相位
        """
        # 从旧RSU移除
        self.vehicle_leave(vehicle_id)

        # 在新RSU分配
        return self.vehicle_enter(vehicle_id, new_rsu_id)

    def get_rsu_load(self, rsu_id: int) -> int:
        """获取RSU当前服务的车辆数"""
        return len(self.rsu_phases.get(rsu_id, {}))

    def get_vehicle_phase(self, vehicle_id: int) -> Optional[float]:
        """获取车辆当前相位"""
        rsu_id = self.vehicle_rsu.get(vehicle_id)
        if rsu_id is None:
            return None
        return self.rsu_phases.get(rsu_id, {}).get(vehicle_id)
```
