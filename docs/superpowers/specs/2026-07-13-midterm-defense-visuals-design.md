# 中期答辩核心图表与算法命名设计

## 1. 目标与交付范围

为专业学位硕士中期答辩生成一组直观、精美且证据严谨的中文图表，并同步更新现有 17 页中期答辩 PPT。交付包括：

1. 五张独立图，均提供高分辨率 PNG 和矢量 PDF；
2. 一张算法选择表，提供 PNG/PDF，并在 PPT 中保持可编辑文本与表格结构；
3. 更新后的 `中期答辩_关铭锡.pptx`，总页数保持 17 页；
4. 图表生成源代码、内容检查与视觉 QA 记录。

图表全部使用中文。`UAV`、`NOMA`、`MEC`、`SIC`、`CSI` 等标准缩写和数学符号保留英文形式。

## 2. 算法命名

### 2.1 总体算法

- 中文：外部性感知与截止时间驱动的联合调度资源分配算法
- 英文：Externality-Aware and Deadline-Driven Joint Scheduling and Resource Allocation
- 缩写：`EAD-JSRA`

### 2.2 创新点一

- 中文：干扰外部性感知的跨无人机关联配对算法
- 英文：Interference-Externality-Aware Cross-UAV Association and Pairing
- 缩写：`IEA-CAP`

### 2.3 创新点二

- 中文：截止时间驱动的最小成本准入分配算法
- 英文：Deadline-Driven Minimum-Cost Admission and Allocation
- 缩写：`DD-MCAA`

代码和 canonical 产物中的方法键 `full` 保持不变，避免破坏复现契约；论文、答辩和新图表将其显示为 `EAD-JSRA（本文算法）`。

## 3. 视觉体系

采用“学术证据型”视觉方向：白色背景、深青色主结构、绿色表示资源模块和已完成状态、暗红表示干扰、硬约束和风险、灰色表示支撑信息。整体与现有答辩材料一致，但减少装饰性卡片，增强因果关系、算法流向和证据层级。

统一规范：

- 16:9 画布，适配宽屏答辩；
- 每张图只回答一个核心问题；
- 标题明确表达结论或问题，不使用空泛标题；
- 主体字号在投影环境中可读，独立 PNG 输出至少 2400×1350；
- 箭头只表达数据流、控制流或因果关系；
- 所有图包含适用边界或结论限定，禁止“全局最优”“大幅提升”等超出证据的表达；
- 不使用外部素材、移动轨迹图或与当前固定悬停模型冲突的无人机照片。

## 4. 六项视觉资产

### 4.1 图 1：选题背景因果图

标题：`选题背景：全频复用多无人机 NOMA-MEC 的任务时限矛盾`

内容从左到右分为：

1. 应用需求：应急巡检、临时热点、独立计算任务与绝对截止时刻；
2. 系统耦合：服务归属、跨 UAV 同频干扰、NOMA/SIC、MEC CPU 同时变化；
3. 研究目标：联合决定关联、配对、卸载和算力，最大化按时完成任务数。

图中使用简洁的双 UAV、地面用户和同频干扰示意，但不画飞行轨迹。底部标注边界：固定悬停、集中式控制、时隙级调度、不优化轨迹与功率。

### 4.2 图 2：EAD-JSRA 总体研究框架

标题：`总体研究框架：EAD-JSRA 的双创新候选评价闭环`

主流程：

`唯一任务与信道快照 → 每 UAV MILP 可行初始化与 SIC 修复 → IEA-CAP 候选调度 → 统一信道/干扰/SIC 评价 → DD-MCAA 资源准入 → 完成集合与全网目标 → 接受或检查下一候选`。

必须体现：

- DD-MCAA 位于每个候选的完整评价内部；
- 接受候选后重新扫描；
- 终止只表示给定邻域下的局部最优；
- 底部证据链为统一轨迹、配对统计、7/7 门禁、canonical v1 和论文图表。

### 4.3 图 3：IEA-CAP 算法流程

标题：`IEA-CAP：干扰外部性感知的确定性首次改进搜索`

步骤：

1. 每 UAV MILP 从正收益单/双用户候选中产生可行初始化；
2. 确定性 SIC 修复删除违规弱用户并重新规范角色；
3. 生成 Replace、Position、CrossUAV 三类邻域；
4. 按实际服务 UAV 重算信道、跨 UAV 干扰、SIC、CPU 和完成集合；
5. 用全网词典序目标 `Φ=(完成任务数，总截止裕量，负跨 UAV 干扰)` 判断严格改善；
6. 接受首个改善并重新扫描，无改善时输出给定邻域下的局部最优。

图中明确“全网接受准则”不等于一般规模全局最优。

### 4.4 图 4：DD-MCAA 算法流程

标题：`DD-MCAA：deadline 解析最小需求与最大基数准入`

步骤：

1. 计算剩余预算 `T_i=d_i-a_i`；
2. 推导最小卸载比例 `alpha_i^min`；
3. 推导最小 MEC CPU `f_i^min`；
4. 筛除分母非正、速率非法或需求超预算的任务；
5. 按 `(f_i^min, task_id)` 稳定排序；
6. 选择 CPU 预算可容纳的最长前缀；
7. 用统一时延函数复核完成集合。

定理边界：任务价值相同、单 UAV 硬 CPU 预算。图中不把该结论推广到有权任务、跨 UAV CPU 迁移或长期队列。

### 4.5 表 1：算法选择与基线定位

标题：`算法选择依据：为什么采用可行初始化、确定性搜索与解析分配`

对比完整联合枚举、深度强化学习、双边交换匹配、全网联合 MILP 和 EAD-JSRA。列为：候选方案、优势、局限、本文定位。

核心结论：

- 完整枚举仅用于小规模经验参考；
- DRL 适合长期策略，但当前任务强调硬约束、确定性和可复现证据，因此退出核心路线；
- 双边交换匹配作为强基线和接受准则对照；
- MILP 用于每 UAV 可行初始化，不承担一般规模联合求解；
- EAD-JSRA 兼顾硬约束、可解释性和在线运行时间，但只保证给定邻域局部最优。

### 4.6 图 5：研究进度图

标题：`研究进度：核心研究与正式实验完成，进入论文及毕业交付阶段`

工作包：可信模型、IEA-CAP、DD-MCAA、实验与证据工程、论文定稿、毕业答辩。前四项为已完成；论文定稿和毕业答辩为进行中。

## 6. 数据与证据边界

所有正式数值只读取 `artifacts/canonical/v1/` 及其生成资产。新视觉不得改变以下口径：

- EAD-JSRA 按时完成率 98.11%，95% CI [97.94%, 98.26%]；
- IEA-CAP 中 CrossUAV 和全网接受准则贡献分别约 +0.05 和 +0.12 个百分点；
- DD-MCAA 相对 crossing/equal 贡献 +8.69 个百分点；
- 最终调度 SIC 与 CPU 预算违规均为 0；
- N=20 调度运行时间 P95 为 40.93 ms；
- 小规模枚举差距为 0 只作为已枚举实例的经验参考。
