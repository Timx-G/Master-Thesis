## 第一部分：研究概述

### 1.1 研究背景

#### 1.1.1 V2X与协作感知

车联网（V2X, Vehicle-to-Everything）是实现自动驾驶和智能交通的关键技术。在V2X系统中，车辆需要通过传感器（摄像头、激光雷达、毫米波雷达）感知周围环境，并通过协作感知消息（CPM, Cooperative Perception Message）与周围车辆和路侧单元（RSU）共享感知信息。

#### 1.1.2 移动边缘计算（MEC）

车载计算资源有限，难以实时处理大量传感器数据。移动边缘计算将计算能力下沉到网络边缘（如RSU），为车辆提供低延迟的计算服务。

#### 1.1.3 周期性任务的特殊性

与传统移动计算场景不同，V2X感知任务具有明显的**周期性特征**：

- 传感器采样是周期性的（摄像头30Hz，激光雷达10-20Hz）
- CPM消息生成遵循ETSI标准的触发规则
- 任务之间存在时序相关性

**现有研究的不足**：绝大多数MEC卸载研究假设任务随机到达（泊松分布），忽略了V2X任务的周期性特征，导致资源预留不准确和周期性拥塞。

### 1.2 研究目标

设计一套完整的V2X场景下周期性任务计算卸载方案，包括：

1. **精确的任务建模**：基于ETSI CPM标准的事件触发周期模型
2. **智能的卸载决策**：利用周期性进行预测和联合优化
3. **高效的调度机制**：通过相位对齐避免同步拥塞
4. **连续的服务保障**：移动感知的服务迁移策略

### 1.3 创新点总结

| 创新点 | 内容 | 理论贡献 |
|--------|------|----------|
| **创新点1** | 事件触发的周期性任务模型 | 首次将ETSI CPM触发规则融入计算卸载建模 |
| **创新点2** | 预测式联合卸载优化 | 基于Lyapunov的在线优化算法，有理论性能保证 |
| **创新点3** | 相位对齐调度机制 | 消除周期性同步拥塞，降低峰值负载 |
| **创新点4** | 移动感知服务迁移 | 保证周期性任务的服务连续性 |
