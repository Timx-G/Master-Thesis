## 一、当前进展总结

### Phase A（已完成）：Single-UAV DC-PPO
- 论文草稿已完成（paper/main.tex）
- **核心发现**：Fixed-lambda=5 PPO在5/5种子中全胜DC-PPO（+3.6pp），说明自适应lambda机制在单UAV小场景中无价值
- **根因**：200m区域+100m高度下，UAV覆盖所有用户，位置优化无意义

### Phase B（进行中）：Multi-UAV Grouped NOMA
- 扩展到800m区域、2架UAV、20用户
- 从20用户全频NOMA改为Grouped NOMA（5子载波×2用户NOMA pair），更符合工程实践
- KKT闭式解替代启发式optimizer，经数值验证精度0.000%

## 二、关键实验结果

### 最终数据（Grouped NOMA环境，t_max=0.7s）

| 算法 | Deadline满足率 |
|------|--------------|
| Independent PPO (DRL) | 61.9% ± 0.8% |
| Hover中心 + alpha=0.95 | **66.8%** |
| 最优静态位置 + alpha=0.95 | **68.4%** |
| HandCraft巡逻 | 50.2% |
| BCD-greedy | 49.8% |
| Hover中心 + alpha=0.5 | 47.5% |

### 核心发现

**DRL学到的唯一有效策略是将offloading参数alpha设为0.95**（从默认0.5到最优0.95，提升+19.3pp）。但这个最优值通过简单的参数网格搜索即可获得。

**DRL的轨迹优化（无人机飞行路径规划）实际上是负贡献（-4.9pp）**。悬停不动比学习飞行更好。

## 三、6轮实验的统一结论

| 轮次 | 尝试 | 结果 |
|------|------|------|
| Phase A | 单UAV 200m | 固定参数全胜DRL |
| Phase B-1 | 20用户全频NOMA + KKT | UAV位置gap < 1pp |
| Phase B-2 | 加MEC容量排队 | UAV位置gap < 1pp |
| Phase B-3 | 改物理参数 | 数学证明delay对信道质量偏导≈0 |
| Phase B-4 | 修正率估算bug | UAV位置gap < 2pp |
| Phase B-5 | Grouped NOMA | 悬停(66.8%) > DRL飞行(61.9%) |

**统一根因**：在100m高度的空地LoS信道下，UAV覆盖范围大，路径损耗对水平距离不敏感。KKT闭式解能自适应补偿信道差异（远用户减少offload，近用户增加offload）。因此，**UAV位置对最终卸载时延几乎无影响**。

## 四、对轨迹优化无价值的数学解释

KKT等延迟条件下的最优时延：

```
delay* = C/f_local × (D/R + C/f_alloc) / (C/f_local + D/R + C/f_alloc)
```

当传输时延D/R（6-8ms）远小于MEC计算时延C/f_alloc（500-600ms）时：

```
UAV在50m处:  delay = 446.6ms
UAV在400m处: delay = 447.8ms
差异: 1.2ms (0.27%)
```

**传输时间占总时延的1-2%，MEC计算占98%。信道质量（UAV位置决定）对时延几乎无影响。**

## 五、两个可能的调整方向

### 方向A：Pivot到NOMA资源分配（不做轨迹优化）

固定UAV位置，让DRL解决用户分组+offloading ratio+功率分配的联合优化。

- **优点**：仍属计算卸载，代码大量复用
- **风险**：预验证显示最优分组只比贪心好4.7pp（单slot），episode级别可能缩至2-3pp
- **工期**：约6-8周

### 方向B：换一个DRL确实有不可替代价值的问题

例如：多服务器协同调度、异构任务routing、在线学习场景。

- **优点**：避免在"DRL无价值"的系统中继续投入
- **风险**：需要重新调研和建模
- **工期**：约8-12周

## 八、我的建议

根据6轮实验的充分验证，我建议：

1. **承认轨迹优化在LoS UAV-MEC中的局限性**，这是科学发现不是失败
2. **优先尝试方向A**（2周验证窗口），如果DRL联合优化比贪心分组+KKT组合高5pp以上，继续推进
3. 如果方向A也失败，**方向B需要尽快启动**
4. 无论最终方向，已有的Grouped NOMA系统建模和KKT闭式解可作为**系统级贡献**保留
