# 06 算法设计：资源分配与服务迁移

本文档详细介绍RSU资源分配算法和移动感知的服务迁移策略。

---

## 1. 资源分配问题

### 1.1 问题背景

在Lyapunov优化确定卸载决策后，需要为卸载到RSU的任务分配：
- **计算资源**：CPU频率
- **通信资源**：上行带宽

### 1.2 问题形式化

**给定**：
- RSU $m$ 上的任务集合 $\mathcal{T}_m = \{1, 2, ..., n_m\}$
- 每个任务的参数：数据量 $D_j$，计算量 $C_j$，截止时间 $T_j^{max}$

**决策变量**：
- $f_j$：分配给任务 $j$ 的计算频率
- $B_j$：分配给任务 $j$ 的带宽

**优化目标**：最小化加权总延迟

$$\min_{\mathbf{f}, \mathbf{B}} \sum_{j \in \mathcal{T}_m} w_j \cdot T_j$$

**约束条件**：

$$\sum_{j \in \mathcal{T}_m} f_j \leq F_m^{max} \quad \text{(计算资源约束)}$$

$$\sum_{j \in \mathcal{T}_m} B_j \leq B_m^{total} \quad \text{(带宽约束)}$$

$$T_j \leq T_j^{max}, \quad \forall j \quad \text{(截止时间约束)}$$

$$f_j, B_j > 0, \quad \forall j$$

---

## 2. 延迟模型详解

### 2.1 总延迟分解

$$T_j = T_j^{up} + T_j^{exe} + T_j^{down}$$

### 2.2 各部分延迟

**上传延迟**（与带宽相关）：

$$T_j^{up} = \frac{D_j}{B_j \cdot \log_2(1 + \text{SNR}_j)}$$

简化为：
$$T_j^{up} = \frac{D_j}{r_j(B_j)}$$

其中 $r_j(B_j)$ 是传输速率。

**执行延迟**（与计算频率相关）：

$$T_j^{exe} = \frac{C_j}{f_j}$$

**下载延迟**（通常远小于上传，可简化）：

$$T_j^{down} = \frac{D_j^{result}}{r_j^{down}} \approx 0.1 \cdot T_j^{up}$$

### 2.3 简化的延迟模型

为便于优化，采用简化模型：

$$T_j \approx \frac{D_j}{\eta \cdot B_j} + \frac{C_j}{f_j}$$

其中 $\eta = \log_2(1 + \text{SNR})$ 是频谱效率。

---

## 3. 凸优化求解

### 3.1 问题转化

原问题中 $T_j$ 关于 $f_j$ 和 $B_j$ 是凸函数（在 $f_j, B_j > 0$ 时）。

整个问题是**凸优化问题**，可以高效求解。

### 3.2 KKT条件求解

**拉格朗日函数**：

$$\mathcal{L} = \sum_j w_j T_j + \lambda \left(\sum_j f_j - F_m^{max}\right) + \mu \left(\sum_j B_j - B_m^{total}\right) + \sum_j \nu_j (T_j - T_j^{max})$$

**KKT条件**：

对 $f_j$ 求导：
$$\frac{\partial \mathcal{L}}{\partial f_j} = -w_j \frac{C_j}{f_j^2} + \lambda + \nu_j \cdot \left(-\frac{C_j}{f_j^2}\right) = 0$$

$$\Rightarrow f_j^* = \sqrt{\frac{(w_j + \nu_j) C_j}{\lambda}}$$

类似地，对 $B_j$ 求导：
$$B_j^* = \sqrt{\frac{(w_j + \nu_j) D_j}{\mu \cdot \eta}}$$

### 3.3 闭式解（无截止时间约束时）

当忽略截止时间约束（$\nu_j = 0$）时，有简洁的闭式解：

**计算频率分配**：
$$f_j^* = \frac{\sqrt{w_j C_j}}{\sum_{i} \sqrt{w_i C_i}} \cdot F_m^{max}$$

**带宽分配**：
$$B_j^* = \frac{\sqrt{w_j D_j}}{\sum_{i} \sqrt{w_i D_i}} \cdot B_m^{total}$$

**直观理解**：资源按"权重×需求"的平方根比例分配。

```python
"""
资源分配模块
文件：algorithms/resource_allocator.py
"""

import numpy as np
from scipy.optimize import minimize, LinearConstraint
from typing import List, Dict, Optional, Tuple
from dataclasses import dataclass


@dataclass
class TaskForAllocation:
    """用于资源分配的任务信息"""
    id: str
    data_size: float      # bits
    compute_load: float   # cycles
    deadline: float       # seconds
    weight: float = 1.0   # 优先级权重
    snr: float = 10.0     # 信噪比（线性）


class ResourceAllocator:
    """
    RSU资源分配器
    """

    def __init__(self):
        pass

    def allocate(self,
                 tasks: List[TaskForAllocation],
                 max_freq: float,
                 max_bandwidth: float,
                 method: str = 'closed_form') -> Dict[str, Dict[str, float]]:
        """
        为任务分配资源

        Args:
            tasks: 任务列表
            max_freq: RSU最大计算频率 (Hz)
            max_bandwidth: RSU最大带宽 (Hz)
            method: 求解方法 ('closed_form' 或 'scipy')

        Returns:
            allocation: {task_id: {'freq': f, 'bandwidth': B, 'delay': T}}
        """
        if not tasks:
            return {}

        if method == 'closed_form':
            return self._closed_form_allocation(tasks, max_freq, max_bandwidth)
        else:
            return self._scipy_allocation(tasks, max_freq, max_bandwidth)

    def _closed_form_allocation(self,
                                 tasks: List[TaskForAllocation],
                                 max_freq: float,
                                 max_bandwidth: float) -> Dict[str, Dict]:
        """
        闭式解资源分配（忽略截止时间约束）
        """
        n = len(tasks)

        # 计算分配比例的分母
        freq_denom = sum(np.sqrt(t.weight * t.compute_load) for t in tasks)
        bw_denom = sum(np.sqrt(t.weight * t.data_size) for t in tasks)

        allocation = {}

        for task in tasks:
            # 计算频率分配
            freq_ratio = np.sqrt(task.weight * task.compute_load) / freq_denom
            freq = freq_ratio * max_freq

            # 带宽分配
            bw_ratio = np.sqrt(task.weight * task.data_size) / bw_denom
            bandwidth = bw_ratio * max_bandwidth

            # 计算延迟
            spectral_efficiency = np.log2(1 + task.snr)
            delay_tx = task.data_size / (bandwidth * spectral_efficiency)
            delay_exe = task.compute_load / freq
            total_delay = delay_tx + delay_exe

            allocation[task.id] = {
                'freq': freq,
                'bandwidth': bandwidth,
                'delay': total_delay,
                'delay_tx': delay_tx,
                'delay_exe': delay_exe
            }

        return allocation

    def _scipy_allocation(self,
                          tasks: List[TaskForAllocation],
                          max_freq: float,
                          max_bandwidth: float) -> Dict[str, Dict]:
        """
        使用scipy优化求解（支持截止时间约束）
        """
        n = len(tasks)

        # 决策变量: [f_1, ..., f_n, B_1, ..., B_n]
        x0 = np.concatenate([
            np.ones(n) * max_freq / n,
            np.ones(n) * max_bandwidth / n
        ])

        # 目标函数：加权总延迟
        def objective(x):
            f = x[:n]
            B = x[n:]
            total_delay = 0
            for j, task in enumerate(tasks):
                eta = np.log2(1 + task.snr)
                delay_tx = task.data_size / (B[j] * eta + 1e-10)
                delay_exe = task.compute_load / (f[j] + 1e-10)
                total_delay += task.weight * (delay_tx + delay_exe)
            return total_delay

        # 目标函数梯度（可选，加速收敛）
        def gradient(x):
            f = x[:n]
            B = x[n:]
            grad = np.zeros(2 * n)
            for j, task in enumerate(tasks):
                eta = np.log2(1 + task.snr)
                # 对f_j的梯度
                grad[j] = -task.weight * task.compute_load / (f[j]**2 + 1e-10)
                # 对B_j的梯度
                grad[n + j] = -task.weight * task.data_size / ((B[j]**2) * eta + 1e-10)
            return grad

        # 约束
        # 计算资源约束: sum(f) <= max_freq
        A_freq = np.zeros((1, 2*n))
        A_freq[0, :n] = 1
        constraint_freq = LinearConstraint(A_freq, -np.inf, max_freq)

        # 带宽约束: sum(B) <= max_bandwidth
        A_bw = np.zeros((1, 2*n))
        A_bw[0, n:] = 1
        constraint_bw = LinearConstraint(A_bw, -np.inf, max_bandwidth)

        # 边界: f, B > 0
        bounds = [(1e6, max_freq)] * n + [(1e3, max_bandwidth)] * n

        # 求解
        result = minimize(
            objective,
            x0,
            method='SLSQP',
            jac=gradient,
            bounds=bounds,
            constraints=[constraint_freq, constraint_bw],
            options={'maxiter': 100}
        )

        # 解析结果
        allocation = {}
        f_opt = result.x[:n]
        B_opt = result.x[n:]

        for j, task in enumerate(tasks):
            eta = np.log2(1 + task.snr)
            delay_tx = task.data_size / (B_opt[j] * eta)
            delay_exe = task.compute_load / f_opt[j]

            allocation[task.id] = {
                'freq': f_opt[j],
                'bandwidth': B_opt[j],
                'delay': delay_tx + delay_exe,
                'delay_tx': delay_tx,
                'delay_exe': delay_exe
            }

        return allocation

    def allocate_with_deadline(self,
                                tasks: List[TaskForAllocation],
                                max_freq: float,
                                max_bandwidth: float) -> Tuple[Dict[str, Dict], bool]:
        """
        带截止时间约束的资源分配

        Returns:
            allocation: 资源分配结果
            feasible: 是否所有任务都能满足截止时间
        """
        # 首先尝试不考虑截止时间
        allocation = self._closed_form_allocation(tasks, max_freq, max_bandwidth)

        # 检查可行性
        feasible = True
        for task in tasks:
            if allocation[task.id]['delay'] > task.deadline:
                feasible = False
                break

        if not feasible:
            # 使用更复杂的方法重新分配
            allocation = self._deadline_aware_allocation(
                tasks, max_freq, max_bandwidth
            )

            # 再次检查
            feasible = all(
                allocation[task.id]['delay'] <= task.deadline
                for task in tasks
            )

        return allocation, feasible

    def _deadline_aware_allocation(self,
                                    tasks: List[TaskForAllocation],
                                    max_freq: float,
                                    max_bandwidth: float) -> Dict[str, Dict]:
        """
        截止时间感知的资源分配

        策略：给紧迫任务更多资源
        """
        # 计算每个任务的紧迫度
        urgencies = []
        for task in tasks:
            # 估计最小延迟（给所有资源时）
            eta = np.log2(1 + task.snr)
            min_delay = task.data_size / (max_bandwidth * eta) + task.compute_load / max_freq
            urgency = min_delay / task.deadline  # 越接近1越紧迫
            urgencies.append(urgency)

        # 根据紧迫度调整权重
        adjusted_weights = []
        for i, task in enumerate(tasks):
            # 紧迫任务权重增加
            adjusted_weight = task.weight * (1 + urgencies[i])
            adjusted_weights.append(adjusted_weight)

        # 创建调整后的任务列表
        adjusted_tasks = []
        for i, task in enumerate(tasks):
            adjusted_task = TaskForAllocation(
                id=task.id,
                data_size=task.data_size,
                compute_load=task.compute_load,
                deadline=task.deadline,
                weight=adjusted_weights[i],
                snr=task.snr
            )
            adjusted_tasks.append(adjusted_task)

        # 使用调整后的权重分配
        return self._closed_form_allocation(adjusted_tasks, max_freq, max_bandwidth)
```

## 5. 服务迁移策略

### 5.1 问题背景

**挑战**：V2X场景中，车辆持续移动，可能离开当前服务RSU的覆盖范围。

**目标**：确保周期性任务的服务连续性，避免中断。

### 5.2 迁移触发条件

```
迁移触发条件检查流程：

1. 覆盖范围检测
   ├── 当前距离 > R - margin?
   │   └── 是 → 考虑迁移
   │   └── 否 → 不迁移
   │
2. 迁移收益评估
   ├── 收益 > 代价 × θ?
   │   └── 是 → 触发迁移
   │   └── 否 → 不迁移
```

### 5.3 迁移收益与代价模型

**迁移收益**（未来K个时隙的累计收益）：

$$\text{Benefit} = \sum_{j=1}^{K} \gamma^j \cdot \left[ T_{src}(k+j) - T_{dst}(k+j) \right]$$

其中 $\gamma < 1$ 是折扣因子。

**迁移代价**：

$$\text{Cost} = T_{transfer} + T_{interruption}$$

- $T_{transfer}$：状态传输时间
- $T_{interruption}$：服务中断时间

### 5.4 迁移策略

#### 策略1：预判式迁移（Proactive Migration）

在车辆离开前提前迁移，利用周期边界减少中断。

```
预判式迁移流程：

1. 预测车辆轨迹
2. 估计离开当前RSU的时刻
3. 在周期边界时刻启动迁移
4. 迁移完成后，新周期在新RSU执行
```

#### 策略2：检查点迁移（Checkpoint Migration）

利用周期性任务的周期边界作为自然检查点。

```
检查点迁移流程：

周期 k:
├── 任务执行
├── 周期结束时保存状态
└── 状态传输到新RSU（与下一周期并行）

周期 k+1:
├── 在新RSU恢复状态
└── 继续执行
```

### 5.5 Python实现

```python
"""
服务迁移管理模块
文件：algorithms/migration_manager.py
"""

import numpy as np
from typing import List, Dict, Optional, Tuple
from dataclasses import dataclass


@dataclass
class MigrationDecision:
    """迁移决策"""
    vehicle_id: int
    source_rsu_id: int
    target_rsu_id: int
    trigger_slot: int
    expected_benefit: float
    expected_cost: float


@dataclass
class MigrationResult:
    """迁移结果"""
    success: bool
    transfer_time: float = 0.0
    interruption_time: float = 0.0
    error: str = ""


class MigrationManager:
    """
    服务迁移管理器
    """

    def __init__(self,
                 lookahead_slots: int = 10,
                 margin: float = 50.0,
                 benefit_threshold: float = 1.2,
                 discount_factor: float = 0.9):
        """
        初始化迁移管理器

        Args:
            lookahead_slots: 预判窗口（时隙数）
            margin: 覆盖边缘裕度（米）
            benefit_threshold: 收益阈值（收益/代价 > 阈值才迁移）
            discount_factor: 未来收益折扣因子
        """
        self.K = lookahead_slots
        self.margin = margin
        self.theta = benefit_threshold
        self.gamma = discount_factor

        # 迁移状态跟踪
        self.in_progress: Dict[int, Dict] = {}  # vehicle_id -> migration_info

    def check_migration(self,
                        vehicle,
                        current_rsu,
                        all_rsus: List,
                        predictor) -> Optional[MigrationDecision]:
        """
        检查是否需要迁移

        Args:
            vehicle: 车辆对象
            current_rsu: 当前服务的RSU
            all_rsus: 所有RSU列表
            predictor: 轨迹预测器

        Returns:
            decision: 迁移决策（如果需要）
        """
        # 已有迁移进行中
        if vehicle.id in self.in_progress:
            return None

        # 预测未来位置
        future_positions = self._predict_positions(vehicle, predictor)

        # 估计离开当前RSU的时隙
        exit_slot = self._estimate_exit_slot(
            vehicle.position, current_rsu, future_positions
        )

        if exit_slot is None or exit_slot > self.K:
            return None  # 不会很快离开

        # 寻找候选目标RSU
        candidates = self._find_candidates(
            current_rsu, all_rsus, future_positions, exit_slot
        )

        if not candidates:
            return None

        # 评估各候选RSU
        best_rsu = None
        best_net_benefit = -float('inf')

        for rsu in candidates:
            benefit = self._calc_benefit(
                vehicle, current_rsu, rsu, future_positions
            )
            cost = self._calc_cost(vehicle, current_rsu, rsu)
            net_benefit = benefit - cost

            if net_benefit > best_net_benefit:
                best_net_benefit = net_benefit
                best_rsu = rsu
                best_benefit = benefit
                best_cost = cost

        # 判断是否值得迁移
        if best_rsu is not None and best_benefit > self.theta * best_cost:
            return MigrationDecision(
                vehicle_id=vehicle.id,
                source_rsu_id=current_rsu.id,
                target_rsu_id=best_rsu.id,
                trigger_slot=0,  # 当前时隙
                expected_benefit=best_benefit,
                expected_cost=best_cost
            )

        return None

    def execute_migration(self,
                          decision: MigrationDecision,
                          vehicle,
                          source_rsu,
                          target_rsu) -> MigrationResult:
        """
        执行迁移

        Args:
            decision: 迁移决策
            vehicle: 车辆对象
            source_rsu: 源RSU
            target_rsu: 目标RSU

        Returns:
            result: 迁移结果
        """
        # 记录迁移进行中
        self.in_progress[vehicle.id] = {
            'decision': decision,
            'state': 'transferring'
        }

        try:
            # Step 1: 保存状态
            state_size = vehicle.get_task_state_size()

            # Step 2: 传输状态
            backhaul_rate = source_rsu.get_backhaul_rate(target_rsu)
            transfer_time = state_size / backhaul_rate

            # Step 3: 更新车辆的服务RSU
            vehicle.current_rsu = target_rsu

            # 清理
            del self.in_progress[vehicle.id]

            return MigrationResult(
                success=True,
                transfer_time=transfer_time,
                interruption_time=0  # 检查点迁移无中断
            )

        except Exception as e:
            del self.in_progress[vehicle.id]
            return MigrationResult(success=False, error=str(e))

    def _predict_positions(self, vehicle, predictor) -> List[np.ndarray]:
        """预测未来位置"""
        positions = []
        current_pos = vehicle.position.copy()
        velocity = vehicle.speed * np.array([np.cos(vehicle.heading),
                                              np.sin(vehicle.heading)])

        for j in range(self.K):
            next_pos = current_pos + velocity * 0.1  # T_check = 0.1s
            positions.append(next_pos.copy())
            current_pos = next_pos

        return positions

    def _estimate_exit_slot(self,
                            current_pos: np.ndarray,
                            rsu,
                            future_positions: List[np.ndarray]) -> Optional[int]:
        """估计离开RSU覆盖范围的时隙"""
        for j, pos in enumerate(future_positions):
            distance = np.linalg.norm(pos - rsu.position)
            if distance > rsu.coverage_radius - self.margin:
                return j
        return None

    def _find_candidates(self,
                         current_rsu,
                         all_rsus: List,
                         future_positions: List[np.ndarray],
                         exit_slot: int) -> List:
        """寻找候选目标RSU"""
        candidates = []
        future_pos = future_positions[min(exit_slot, len(future_positions) - 1)]

        for rsu in all_rsus:
            if rsu.id == current_rsu.id:
                continue
            distance = np.linalg.norm(future_pos - rsu.position)
            if distance < rsu.coverage_radius:
                candidates.append(rsu)

        return candidates

    def _calc_benefit(self,
                      vehicle,
                      src_rsu,
                      dst_rsu,
                      future_positions: List[np.ndarray]) -> float:
        """计算迁移收益"""
        benefit = 0

        for j, pos in enumerate(future_positions):
            # 在源RSU的预期延迟
            dist_src = np.linalg.norm(pos - src_rsu.position)
            delay_src = self._estimate_delay(vehicle, src_rsu, dist_src)

            # 在目标RSU的预期延迟
            dist_dst = np.linalg.norm(pos - dst_rsu.position)
            delay_dst = self._estimate_delay(vehicle, dst_rsu, dist_dst)

            # 带折扣的收益
            benefit += (self.gamma ** j) * (delay_src - delay_dst)

        return benefit

    def _calc_cost(self, vehicle, src_rsu, dst_rsu) -> float:
        """计算迁移代价"""
        state_size = vehicle.get_task_state_size()
        backhaul_rate = src_rsu.get_backhaul_rate(dst_rsu)
        transfer_time = state_size / backhaul_rate

        # 简化的中断代价
        interruption_cost = transfer_time * 0.5

        return transfer_time + interruption_cost

    def _estimate_delay(self, vehicle, rsu, distance: float) -> float:
        """估计在给定距离下的延迟"""
        # 简化的路径损耗模型
        path_loss = 1e-4 * (distance ** (-3.5))
        snr = vehicle.tx_power * path_loss / rsu.noise_power
        rate = rsu.bandwidth * np.log2(1 + snr)

        # 假设平均任务参数
        avg_data = 1e6  # 1 MB
        avg_compute = 200e6  # 200 MCycles

        delay_tx = avg_data / rate
        delay_exe = avg_compute / (rsu.max_freq / 10)

        return delay_tx + delay_exe

    def get_migration_stats(self) -> Dict:
        """获取迁移统计信息"""
        return {
            'in_progress_count': len(self.in_progress),
            'in_progress_vehicles': list(self.in_progress.keys())
        }
```
