# 附录B：DPA算法的竞争比分析

本文档提供分布式相位调整（DPA）算法的竞争比理论证明。

---

## 1. 问题定义

### 1.1 Min-Max Gap问题

**问题描述**：给定检查周期 $T$（为简化记号，后文用 $T$ 代替 $T_{check}$），需要为 $n$ 辆依次到达的车辆分配相位 $\phi_1, \phi_2, \ldots, \phi_n \in [0, T)$，使得**最大相位间隔最小化**。

**相位间隔定义**：设相位按升序排列为 $\phi_{(1)} \leq \phi_{(2)} \leq \cdots \leq \phi_{(n)}$，则相邻间隔为：

$$g_i = \begin{cases}
\phi_{(i+1)} - \phi_{(i)}, & i = 1, 2, \ldots, n-1 \\
T - \phi_{(n)} + \phi_{(1)}, & i = n \quad \text{（环形边界）}
\end{cases}$$

**目标**：最小化最大间隔

$$G_{max} = \max_{i=1,\ldots,n} g_i$$

### 1.2 在线设定

**在线问题特征**：
- 车辆**依次到达**，到达时必须立即分配相位
- 分配后**不可修改**（或修改成本极高）
- 算法在分配时**不知道**未来车辆的数量和到达顺序

**离线最优解**：如果预先知道车辆总数 $n$，最优解是**均匀分配**：

$$\phi_i^* = \frac{(i-1) \cdot T}{n}, \quad i = 1, 2, \ldots, n$$

此时最优最大间隔为：

$$G_{max}^* = \text{OPT}(n) = \frac{T}{n}$$

### 1.3 竞争比定义

**定义（竞争比）**：对于在线算法 $\mathcal{A}$，其竞争比（Competitive Ratio）定义为：

$$\rho(\mathcal{A}) = \sup_{\sigma} \frac{G_{max}^{\mathcal{A}}(\sigma)}{G_{max}^*(\sigma)}$$

其中 $\sigma$ 表示任意车辆到达序列，$G_{max}^{\mathcal{A}}(\sigma)$ 是算法 $\mathcal{A}$ 在序列 $\sigma$ 上产生的最大间隔，$G_{max}^*(\sigma)$ 是该序列的离线最优解。

**目标**：证明DPA算法的竞争比 $\rho(\text{DPA}) \leq 2$。

---

## 2. DPA算法回顾

### 2.1 算法描述

**DPA（Distributed Phase Adjustment）策略**：

当第 $k$ 辆车到达时（$k \geq 1$）：
1. 如果 $k = 1$：分配 $\phi_1 = 0$
2. 如果 $k > 1$：
   - 计算当前所有相位间隔 $\{g_1, g_2, \ldots, g_{k-1}\}$
   - 找到最大间隔 $g_{max} = \max_i g_i$，设其两端点为 $\phi_a$ 和 $\phi_b$
   - 将新相位分配为最大间隔的**中点**：$\phi_k = (\phi_a + \phi_b) / 2$

### 2.2 算法示例

设 $T = 100$ ms，车辆依次到达：

| 车辆 | 到达前相位 | 间隔 | 最大间隔 | 分配相位 |
|------|-----------|------|----------|----------|
| 1 | $\emptyset$ | - | - | $\phi_1 = 0$ |
| 2 | $\{0\}$ | $[0, 100)$ | 100 | $\phi_2 = 50$ |
| 3 | $\{0, 50\}$ | $[0,50), [50,100)$ | 50 | $\phi_3 = 25$ 或 $75$ |
| 4 | $\{0, 25, 50\}$ | $[0,25), [25,50), [50,100)$ | 50 | $\phi_4 = 75$ |
| 5 | $\{0, 25, 50, 75\}$ | 各25 | 25 | $\phi_5 = 12.5$ |

## 3. 竞争分析

### 3.1 引理1：间隔二分性质

**引理1**：设DPA算法在分配第 $k$ 辆车之前的最大间隔为 $G_k$。分配第 $k$ 辆车后，新的最大间隔 $G_{k+1}$ 满足：

$$G_{k+1} \leq \max\left(\frac{G_k}{2}, G_k^{(2)}\right)$$

其中 $G_k^{(2)}$ 是分配前的**第二大间隔**。

**证明**：

DPA将新相位放在最大间隔 $G_k$ 的中点，将其分为两个等长间隔，每个长度为 $G_k/2$。

分配后的间隔集合变为：
- 原最大间隔被替换为两个 $G_k/2$ 的间隔
- 其他间隔不变

因此，新的最大间隔 $G_{k+1} = \max(G_k/2, G_k^{(2)})$。 $\square$

### 3.2 引理2：间隔比值上界

**引理2**：在DPA算法执行过程中，任意时刻任意两个相邻间隔的比值不超过2。

**证明**（归纳法）：

**基础情况**：$n = 2$ 时，两个间隔分别为 $T/2$ 和 $T/2$，比值为1。

**归纳假设**：设 $n = k$ 时成立，即任意两个间隔 $g_i, g_j$ 满足 $g_i / g_j \leq 2$。

**归纳步骤**：当第 $k+1$ 辆车到达时，DPA将最大间隔 $G_k$ 二分为两个 $G_k/2$ 的间隔。

设其他间隔中最大的为 $g_{other}$，由归纳假设：$G_k / g_{other} \leq 2$，即 $g_{other} \geq G_k/2$。

分配后：
- 新产生的间隔：$G_k/2$
- 原有间隔：$g_{other} \geq G_k/2$

任意两个间隔的比值：
$$\frac{\max(G_k/2, g_{other})}{\min(G_k/2, g_{other})} \leq \frac{g_{other}}{G_k/2} \leq \frac{G_k}{G_k/2} = 2$$

故归纳假设对 $n = k+1$ 也成立。 $\square$

### 3.3 引理3：最大间隔上界

**引理3**：DPA算法分配 $n$ 辆车后，最大间隔 $G_n^{DPA}$ 满足：

$$G_n^{DPA} \leq \frac{2T}{n}$$

**证明**：

由引理2，任意两个间隔的比值不超过2。设 $n$ 个间隔为 $g_1, g_2, \ldots, g_n$。

由于所有间隔之和为 $T$：
$$\sum_{i=1}^{n} g_i = T$$

设最大间隔为 $G_n^{DPA}$，最小间隔为 $g_{min}$。由引理2：
$$g_{min} \geq \frac{G_n^{DPA}}{2}$$

因此：
$$T = \sum_{i=1}^{n} g_i \geq n \cdot g_{min} \geq n \cdot \frac{G_n^{DPA}}{2}$$

解得：
$$G_n^{DPA} \leq \frac{2T}{n}$$

$\square$

### 3.4 定理：2-竞争比

**定理（DPA的竞争比）**：DPA算法是**2-competitive**的，即对于任意车辆到达序列：

$$\frac{G_{max}^{DPA}}{G_{max}^*} \leq 2$$

**证明**：

由引理3，DPA产生的最大间隔 $G_n^{DPA} \leq 2T/n$。

离线最优解的最大间隔 $G_n^* = T/n$（均匀分配）。

因此：
$$\rho(\text{DPA}) = \frac{G_n^{DPA}}{G_n^*} \leq \frac{2T/n}{T/n} = 2$$

$\square$

## 4. 紧致性分析

### 4.1 下界构造

**命题**：DPA算法的竞争比下界为2，即存在到达序列使得 $G_{max}^{DPA} / G_{max}^* \to 2$。

**构造**：考虑 $n = 2^k$ 辆车按特定顺序到达。

设 $T = 1$，车辆到达后DPA的分配过程：

| 步骤 | 车辆数 | 相位集合 | 最大间隔 |
|------|--------|----------|----------|
| 1 | 1 | $\{0\}$ | 1 |
| 2 | 2 | $\{0, 0.5\}$ | 0.5 |
| 3 | 3 | $\{0, 0.25, 0.5\}$ 或 $\{0, 0.5, 0.75\}$ | 0.5 |
| 4 | 4 | $\{0, 0.25, 0.5, 0.75\}$ | 0.25 |
| ... | ... | ... | ... |

观察到，当 $n = 2^k + 1$ 时，DPA的最大间隔为 $1/2^k$，而最优解的最大间隔为 $1/(2^k+1)$。

比值：
$$\frac{G^{DPA}}{G^*} = \frac{1/2^k}{1/(2^k+1)} = \frac{2^k+1}{2^k} = 1 + \frac{1}{2^k} \to 1 \quad (k \to \infty)$$

这个构造实际上表明DPA在 $n = 2^k$ 时是**最优的**。

### 4.2 真正达到竞争比2的构造

考虑以下到达序列，$T = 1$：

1. 第1辆车到达：$\phi_1 = 0$，间隔 = $[0, 1)$，最大间隔 = 1
2. 第2辆车到达：$\phi_2 = 0.5$，间隔 = $[0, 0.5), [0.5, 1)$，最大间隔 = 0.5
3. 第3辆车到达：选择 $[0, 0.5)$ 或 $[0.5, 1)$，假设选 $[0.5, 1)$，则 $\phi_3 = 0.75$

此时相位为 $\{0, 0.5, 0.75\}$，间隔为 $\{0.5, 0.25, 0.25\}$，最大间隔 = 0.5。

最优解：$\{0, 1/3, 2/3\}$，最大间隔 = 1/3。

比值：$0.5 / (1/3) = 1.5$

**更一般的构造**：

对于 $n = 3$：
- DPA最坏情况：最大间隔 = $T/2$
- 最优解：最大间隔 = $T/3$
- 比值 = $3/2 = 1.5$

对于 $n = 2^k - 1$：
- DPA可能产生最大间隔 $\approx T/2^{k-1}$
- 最优解最大间隔 = $T/(2^k - 1)$
- 比值 $\to 2$ 当 $k \to \infty$

### 4.3 紧致性结论

**结论**：DPA算法的竞争比**紧致为2**，即：

$$\rho(\text{DPA}) = 2$$

存在输入序列使得比值任意接近2，同时不存在输入使比值超过2。

## 5. 与CPA的对比

### 5.1 性能对比

| 特性 | CPA（集中式） | DPA（分布式） |
|------|--------------|--------------|
| **最优性** | 离线最优（竞争比=1） | 在线2-competitive |
| **信息需求** | 需要知道所有车辆 | 只需当前车辆 |
| **执行时机** | 系统初始化 | 车辆动态加入 |
| **时间复杂度** | $O(MN)$ | $O(k \log k)$ |
| **适用场景** | 稳定场景 | 动态场景 |

### 5.2 混合策略

实际系统中建议采用**混合策略**：

1. **初始化阶段**：使用CPA为初始车辆集分配最优相位
2. **运行阶段**：使用DPA处理动态加入的车辆
3. **定期重平衡**：当相位分布退化时，触发CPA重新分配

### 5.3 实际影响

**定理的实际意义**：

DPA的竞争比为2意味着：
- 最坏情况下，DPA的最大间隔不超过最优解的2倍
- 相应地，峰值负载最多是最优情况的2倍
- 在V2X场景中，这仍然比无相位对齐（所有车辆同时传输）好得多

**数值示例**：
- 100辆车，$T = 100$ ms
- 无对齐：所有车辆可能同时传输
- DPA：最大间隔 $\leq 2$ ms（最多约50辆车在同一2ms窗口传输）
- CPA：最大间隔 = 1 ms（最多约1辆车在同一1ms窗口传输）

## 6. 扩展讨论

### 6.1 加权情形

如果不同车辆有不同的"重要性"权重 $w_i$，目标变为最小化加权最大间隔：

$$G_{max}^{weighted} = \max_i \frac{g_i}{w_i}$$

**扩展DPA**：将新相位分配到加权间隔最大的位置。

### 6.2 多RSU情形

当车辆可能被多个RSU覆盖时，需要考虑：
- 每个RSU独立维护相位分配
- 车辆切换RSU时触发DPA
- 全局优化需要RSU间协调

### 6.3 动态离开

当车辆离开时：
- 简单策略：不调整其他车辆（间隔可能增大）
- 激进策略：触发局部重平衡（额外开销）

本文采用简单策略，实验表明在车辆流动性较高时效果良好。

---

## 7. 总结

本附录证明了DPA算法的以下理论性质：

1. **竞争比上界**：DPA是2-competitive的（定理）
2. **竞争比紧致**：存在输入使比值任意接近2
3. **间隔性质**：任意两个间隔的比值不超过2（引理2）
4. **最大间隔上界**：$G_n^{DPA} \leq 2T/n$（引理3）

这些结果为PAPO框架中的相位对齐调度提供了坚实的理论基础。
