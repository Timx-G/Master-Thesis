# 04 算法设计：任务负载预测

本文档详细介绍利用事件触发周期模型进行任务负载预测的算法设计。

---

## 1. 预测目标

### 1.1 为什么需要预测？

**传统反应式方法的问题**：
- 任务到达后才决策，无法提前准备资源
- 无法利用周期性任务的时序相关性
- 容易造成拥塞或资源浪费

**预测式方法的优势**：
- 提前知道未来任务，可以预留资源
- 利用周期性特征，提高预测准确性
- 联合优化多个周期的决策

### 1.2 预测内容

我们需要预测未来 $K$ 个时隙的：

| 预测项 | 符号 | 说明 |
|--------|------|------|
| 任务生成指示 | $\hat{\alpha}_i(k+j)$ | 是否会生成任务 |
| 数据量 | $\hat{D}_i(k+j)$ | 任务的输入数据量 |
| 计算量 | $\hat{C}_i(k+j)$ | 任务的计算需求 |
| 车辆位置 | $\hat{\mathbf{p}}_i(k+j)$ | 用于RSU选择 |

---

## 2. 基于运动学的预测

### 2.1 核心思想

**关键洞察**：事件触发的任务生成与车辆运动状态直接相关。

- 位置变化超过阈值 → 触发任务
- 速度决定位置变化速率 → 可预测触发时刻

### 2.2 运动学模型

假设车辆在短期内（几个时隙）保持近似匀速直线运动：

**位置预测**：
$$\hat{\mathbf{p}}_i(k+j) = \mathbf{p}_i(k) + j \cdot T_{check} \cdot v_i(k) \cdot [\cos\theta_i(k), \sin\theta_i(k)]^T$$

**累计位移**：
$$\Delta p_i(k, k+j) = \|\hat{\mathbf{p}}_i(k+j) - \mathbf{p}_i(k_{last}^i)\|$$

其中 $k_{last}^i$ 是车辆 $i$ 上一次触发任务的时隙。

### 2.3 触发时刻预测

**预测下一次触发的时隙**：

对于匀速行驶的车辆，触发间隔为：

$$\Delta k = \left\lceil \frac{\Delta p_{th}}{v_i(k) \cdot T_{check}} \right\rceil$$

**下一次触发时隙**：
$$k_{next} = k_{last}^i + \Delta k$$

### 2.4 示例计算

**参数**：
- $T_{check} = 0.1$ s (100 ms)
- $\Delta p_{th} = 4$ m
- 车速 $v = 20$ m/s (72 km/h)

**计算**：
- 每时隙移动：$20 \times 0.1 = 2$ m
- 触发间隔：$\lceil 4/2 \rceil = 2$ 个时隙
- 即每 200 ms 生成一次任务

**不同车速的触发频率**：

| 车速 (m/s) | 车速 (km/h) | 每时隙移动 (m) | 触发间隔 (时隙) | 任务频率 |
|------------|-------------|----------------|-----------------|----------|
| 10 | 36 | 1 | 4 | 2.5 Hz |
| 20 | 72 | 2 | 2 | 5 Hz |
| 30 | 108 | 3 | 2 | 5 Hz |
| 40 | 144 | 4 | 1 | 10 Hz |

### 2.5 算法描述

```
算法 KinematicPredictor：基于运动学的任务预测
════════════════════════════════════════════════════════════════

输入：
  - 车辆当前状态：位置 p_i(k), 速度 v_i(k), 航向 θ_i(k)
  - 上次触发信息：时隙 k_last, 位置 p_last
  - 预测窗口长度：K
  - 触发阈值：Δp_th, Δv_th, T_max

输出：
  - 未来K个时隙的预测：{α̂(k+1), ..., α̂(k+K)}

════════════════════════════════════════════════════════════════

步骤：

1. 初始化：
   累计位移 d_acc = ||p_i(k) - p_last||
   距上次触发时隙数 slots_since = k - k_last

2. FOR j = 1 to K:

   2.1 预测位移增量：
       Δd = v_i(k) × T_check

   2.2 更新累计位移：
       d_acc = d_acc + Δd
       slots_since = slots_since + 1

   2.3 检查触发条件：
       trigger = FALSE

       IF d_acc ≥ Δp_th:          // 条件1：位置变化
           trigger = TRUE
           d_acc = 0

       IF slots_since × T_check ≥ T_max:  // 条件5：最大间隔
           trigger = TRUE

   2.4 记录预测结果：
       IF trigger:
           α̂(k+j) = 1
           slots_since = 0
       ELSE:
           α̂(k+j) = 0

3. RETURN {α̂(k+1), ..., α̂(k+K)}

════════════════════════════════════════════════════════════════
```

## 3. 基于学习的预测增强

### 3.1 为什么需要学习方法？

**运动学预测的局限**：
- 假设匀速直线运动，实际有加减速和转弯
- 难以预测目标检测数量的变化
- 无法捕捉复杂的时序模式

**学习方法的优势**：
- 自动从数据中学习复杂模式
- 适应非线性变化
- 可以融合多种特征

### 3.2 模型架构

采用轻量级GRU网络，平衡效果和效率。

```
输入特征（每个时隙 8 维）：
┌─────────────────────────────────────┐
│ 位置 x                 : 1维        │
│ 位置 y                 : 1维        │
│ 速度 v                 : 1维        │
│ 航向 θ                 : 1维        │
│ 加速度 a               : 1维        │
│ 检测目标数 N_obj       : 1维        │
│ 距上次触发的时隙数     : 1维        │
│ 到最近RSU的距离        : 1维        │
└─────────────────────────────────────┘

模型结构：
Input [batch, H, 8]
    ↓
GRU (hidden=64, layers=2)
    ↓
Hidden [batch, 64]
    ↓
┌─────────────┬─────────────┬─────────────┐
│ α_head      │ D_head      │ C_head      │
│ FC→Sigmoid  │ FC→ReLU     │ FC→ReLU     │
└─────────────┴─────────────┴─────────────┘
    ↓              ↓              ↓
[batch, K]    [batch, K]    [batch, K]
任务生成概率   数据量预测     计算量预测
```

### 3.3 PyTorch实现

```python
"""
任务负载预测模型
文件：algorithms/predictor.py
"""

import torch
import torch.nn as nn
import torch.nn.functional as F
import numpy as np
from typing import Dict, List, Tuple, Optional
from dataclasses import dataclass


@dataclass
class VehicleState:
    """车辆状态"""
    position: np.ndarray      # [x, y]
    speed: float              # m/s
    heading: float            # rad
    acceleration: float       # m/s^2
    num_objects: int          # 检测目标数
    slots_since_last: int     # 距上次触发的时隙数
    distance_to_rsu: float    # 到最近RSU的距离


class TaskPredictorNN(nn.Module):
    """
    基于神经网络的任务预测模型
    """

    def __init__(self,
                 input_dim: int = 8,
                 hidden_dim: int = 64,
                 history_len: int = 10,
                 predict_len: int = 5,
                 dropout: float = 0.1):
        """
        初始化预测模型

        Args:
            input_dim: 输入特征维度
            hidden_dim: 隐藏层维度
            history_len: 历史窗口长度
            predict_len: 预测窗口长度
            dropout: Dropout比例
        """
        super().__init__()

        self.input_dim = input_dim
        self.hidden_dim = hidden_dim
        self.history_len = history_len
        self.predict_len = predict_len

        # GRU编码器
        self.gru = nn.GRU(
            input_size=input_dim,
            hidden_size=hidden_dim,
            num_layers=2,
            batch_first=True,
            dropout=dropout if dropout > 0 else 0
        )

        # 任务生成预测头（二分类）
        self.alpha_head = nn.Sequential(
            nn.Linear(hidden_dim, 32),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(32, predict_len),
            nn.Sigmoid()
        )

        # 数据量预测头（回归，非负）
        self.data_head = nn.Sequential(
            nn.Linear(hidden_dim, 32),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(32, predict_len),
            nn.Softplus()  # 保证非负
        )

        # 计算量预测头（回归，非负）
        self.compute_head = nn.Sequential(
            nn.Linear(hidden_dim, 32),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(32, predict_len),
            nn.Softplus()
        )

    def forward(self, x: torch.Tensor) -> Tuple[torch.Tensor, torch.Tensor, torch.Tensor]:
        """
        前向传播

        Args:
            x: 输入特征 [batch, history_len, input_dim]

        Returns:
            alpha_pred: 任务生成概率 [batch, predict_len]
            data_pred: 数据量预测 [batch, predict_len]
            compute_pred: 计算量预测 [batch, predict_len]
        """
        # GRU编码
        _, hidden = self.gru(x)
        hidden = hidden[-1]  # 取最后一层 [batch, hidden_dim]

        # 三个预测头
        alpha_pred = self.alpha_head(hidden)
        data_pred = self.data_head(hidden)
        compute_pred = self.compute_head(hidden)

        return alpha_pred, data_pred, compute_pred

    def predict(self, history: np.ndarray) -> Dict[str, np.ndarray]:
        """
        预测接口（单样本）

        Args:
            history: 历史特征 [history_len, input_dim]

        Returns:
            predictions: {'alpha': [...], 'data': [...], 'compute': [...]}
        """
        self.eval()
        with torch.no_grad():
            x = torch.FloatTensor(history).unsqueeze(0)  # [1, H, D]
            alpha, data, compute = self.forward(x)

        return {
            'alpha': alpha.squeeze().numpy(),
            'data': data.squeeze().numpy(),
            'compute': compute.squeeze().numpy()
        }


class KinematicPredictor:
    """
    基于运动学的预测器
    """

    def __init__(self,
                 T_check: float = 0.1,
                 delta_p_th: float = 4.0,
                 delta_v_th: float = 0.5,
                 T_max: float = 1.0,
                 D_base: float = 0.5e6,
                 C_base: float = 100e6,
                 eta: float = 50e3,
                 gamma: float = 20e6):
        """
        初始化运动学预测器

        Args:
            T_check: 检查周期 (s)
            delta_p_th: 位置变化阈值 (m)
            delta_v_th: 速度变化阈值 (m/s)
            T_max: 最大触发间隔 (s)
            D_base: 基础数据量 (bits)
            C_base: 基础计算量 (cycles)
            eta: 每目标数据增量 (bits/obj)
            gamma: 每目标计算增量 (cycles/obj)
        """
        self.T_check = T_check
        self.delta_p_th = delta_p_th
        self.delta_v_th = delta_v_th
        self.T_max = T_max
        self.D_base = D_base
        self.C_base = C_base
        self.eta = eta
        self.gamma = gamma

    def predict(self, state: VehicleState, K: int) -> Dict[str, np.ndarray]:
        """
        基于运动学的预测

        Args:
            state: 车辆当前状态
            K: 预测窗口长度

        Returns:
            predictions: {'alpha': [...], 'data': [...], 'compute': [...]}
        """
        alpha_pred = np.zeros(K)
        data_pred = np.zeros(K)
        compute_pred = np.zeros(K)

        # 初始化累计位移
        cumulative_displacement = 0.0
        slots_since_last = state.slots_since_last

        for j in range(K):
            # 预测位移增量
            displacement = state.speed * self.T_check
            cumulative_displacement += displacement
            slots_since_last += 1

            # 检查触发条件
            trigger = False

            # 条件1：位置变化
            if cumulative_displacement >= self.delta_p_th:
                trigger = True
                cumulative_displacement = 0

            # 条件5：最大间隔
            if slots_since_last * self.T_check >= self.T_max:
                trigger = True

            if trigger:
                alpha_pred[j] = 1.0
                # 估计数据量和计算量
                data_pred[j] = self.D_base + self.eta * state.num_objects
                compute_pred[j] = self.C_base + self.gamma * state.num_objects
                slots_since_last = 0

        return {
            'alpha': alpha_pred,
            'data': data_pred,
            'compute': compute_pred
        }

    def predict_next_trigger(self, state: VehicleState) -> int:
        """
        预测下一次触发的时隙数

        Args:
            state: 车辆当前状态

        Returns:
            slots_to_trigger: 距下一次触发的时隙数
        """
        if state.speed < 0.01:  # 静止
            # 只由最大间隔触发
            remaining = self.T_max - state.slots_since_last * self.T_check
            return max(1, int(np.ceil(remaining / self.T_check)))

        # 计算位置触发所需时隙
        remaining_distance = self.delta_p_th  # 简化：假设从0开始累计
        slots_by_position = int(np.ceil(remaining_distance / (state.speed * self.T_check)))

        # 计算最大间隔触发所需时隙
        remaining_time = self.T_max - state.slots_since_last * self.T_check
        slots_by_time = max(1, int(np.ceil(remaining_time / self.T_check)))

        return min(slots_by_position, slots_by_time)


class HybridPredictor:
    """
    混合预测器：结合运动学预测和学习预测
    """

    def __init__(self,
                 nn_model: Optional[TaskPredictorNN] = None,
                 use_learning: bool = True,
                 confidence_threshold: float = 0.7,
                 T_check: float = 0.1):
        """
        初始化混合预测器

        Args:
            nn_model: 神经网络模型（可选）
            use_learning: 是否使用学习预测
            confidence_threshold: 置信度阈值
            T_check: 检查周期
        """
        self.nn_model = nn_model
        self.use_learning = use_learning and (nn_model is not None)
        self.confidence_threshold = confidence_threshold
        self.T_check = T_check

        # 运动学预测器
        self.kinematic_predictor = KinematicPredictor(T_check=T_check)

    def predict(self,
                state: VehicleState,
                history: Optional[np.ndarray] = None,
                K: int = 5) -> Dict[str, np.ndarray]:
        """
        混合预测

        Args:
            state: 车辆当前状态
            history: 历史特征（用于学习预测）
            K: 预测窗口长度

        Returns:
            predictions: 预测结果
        """
        # 运动学预测（始终执行）
        kinematic_pred = self.kinematic_predictor.predict(state, K)

        if not self.use_learning or history is None:
            return kinematic_pred

        # 学习预测
        learning_pred = self.nn_model.predict(history)

        # 融合策略
        speed_variation = self._calc_speed_variation(history)

        if speed_variation < self.confidence_threshold:
            # 速度稳定，运动学预测可靠
            return kinematic_pred
        else:
            # 速度变化大，融合两种预测
            return self._fuse_predictions(kinematic_pred, learning_pred, speed_variation)

    def _calc_speed_variation(self, history: np.ndarray) -> float:
        """
        计算历史速度变化程度

        Args:
            history: 历史特征 [H, D]，假设第3列是速度

        Returns:
            variation: 变化系数 (标准差/均值)
        """
        speeds = history[:, 2]  # 假设第3列是速度
        mean_speed = np.mean(speeds)
        if mean_speed < 0.01:
            return 0.0
        return np.std(speeds) / mean_speed

    def _fuse_predictions(self,
                          kinematic: Dict[str, np.ndarray],
                          learning: Dict[str, np.ndarray],
                          weight: float) -> Dict[str, np.ndarray]:
        """
        融合两种预测

        Args:
            kinematic: 运动学预测
            learning: 学习预测
            weight: 学习预测权重

        Returns:
            fused: 融合后的预测
        """
        w_learn = min(weight, 0.8)  # 学习权重上限
        w_kine = 1 - w_learn

        return {
            'alpha': w_kine * kinematic['alpha'] + w_learn * learning['alpha'],
            'data': w_kine * kinematic['data'] + w_learn * learning['data'],
            'compute': w_kine * kinematic['compute'] + w_learn * learning['compute']
        }

class PredictorTrainer:
    """
    预测模型训练器
    """

    def __init__(self,
                 model: TaskPredictorNN,
                 learning_rate: float = 1e-3,
                 weight_decay: float = 1e-4):
        """
        初始化训练器

        Args:
            model: 预测模型
            learning_rate: 学习率
            weight_decay: 权重衰减
        """
        self.model = model
        self.optimizer = torch.optim.Adam(
            model.parameters(),
            lr=learning_rate,
            weight_decay=weight_decay
        )

        # 损失函数
        self.bce_loss = nn.BCELoss()  # 二分类交叉熵
        self.mse_loss = nn.MSELoss()  # 均方误差

    def train_step(self,
                   batch_x: torch.Tensor,
                   batch_y: Dict[str, torch.Tensor]) -> Dict[str, float]:
        """
        单步训练

        Args:
            batch_x: 输入 [batch, H, D]
            batch_y: 标签 {'alpha': [batch, K], 'data': [...], 'compute': [...]}

        Returns:
            losses: 各部分损失
        """
        self.model.train()
        self.optimizer.zero_grad()

        # 前向传播
        alpha_pred, data_pred, compute_pred = self.model(batch_x)

        # 计算损失
        loss_alpha = self.bce_loss(alpha_pred, batch_y['alpha'])
        loss_data = self.mse_loss(data_pred, batch_y['data'])
        loss_compute = self.mse_loss(compute_pred, batch_y['compute'])

        # 加权组合
        loss = loss_alpha + 0.1 * loss_data + 0.1 * loss_compute

        # 反向传播
        loss.backward()
        self.optimizer.step()

        return {
            'loss': loss.item(),
            'loss_alpha': loss_alpha.item(),
            'loss_data': loss_data.item(),
            'loss_compute': loss_compute.item()
        }

    def train_epoch(self, dataloader) -> Dict[str, float]:
        """训练一个epoch"""
        total_losses = {'loss': 0, 'loss_alpha': 0, 'loss_data': 0, 'loss_compute': 0}
        num_batches = 0

        for batch_x, batch_y in dataloader:
            losses = self.train_step(batch_x, batch_y)
            for k in total_losses:
                total_losses[k] += losses[k]
            num_batches += 1

        # 平均
        for k in total_losses:
            total_losses[k] /= num_batches

        return total_losses
```

## 4. 预测准确性分析

### 4.1 运动学预测的准确性

**定理（触发时刻预测误差）**：

对于以速度 $v$ 行驶、速度标准差为 $\sigma_v$ 的车辆，触发时刻预测误差满足：

$$\mathbb{E}[|k_{pred} - k_{actual}|] \leq \frac{\sigma_v}{v} \cdot \frac{\Delta p_{th}}{v \cdot T_{check}}$$

**解读**：
- 速度越稳定（$\sigma_v$ 小），预测越准确
- 高速车辆（$v$ 大）的预测误差相对较小

### 4.2 预测误差对AoI的影响

**定理（预测误差与AoI增量）**：

设预测误差参数为 $\varepsilon \in [0, 1]$（0=完美预测，1=随机猜测），则预测误差导致的AoI增量为：

$$\Delta A(\varepsilon) \approx c \cdot \varepsilon \cdot T_{check}$$

其中 $c \in [0.5, 1.5]$ 取决于系统负载。

**关键结论**：
- $\varepsilon < 0.1$：AoI增加 < 10%，**推荐设计目标**
- $\varepsilon < 0.2$：AoI增加 < 20%，可接受
- $\varepsilon > 0.5$：预测优势基本消失

**详细推导**：请参见 [附录C：预测误差理论分析](./04.1_附录C_预测误差理论分析.md)

### 4.3 影响预测准确性的因素

| 因素 | 影响 | 应对策略 |
|------|------|----------|
| 加减速 | 导致触发时刻偏移 | 使用加速度作为特征 |
| 转弯 | 实际位移与预测不同 | 考虑航向变化 |
| 目标数量变化 | 影响数据量/计算量预测 | 使用学习方法 |
| 环境变化 | 突发事件触发 | 保守估计 |

### 4.4 预测窗口选择

| 窗口长度K | 优点 | 缺点 | 推荐场景 |
|-----------|------|------|----------|
| K=1-3 | 准确性高 | 优化空间小 | 实时性要求高 |
| K=5-10 | 平衡 | 平衡 | 一般场景 |
| K>10 | 优化空间大 | 准确性下降 | 预规划场景 |

**推荐**：$K = 5$，覆盖约500ms的未来。

```python
def proactive_resource_reservation(predictions, rsus):
    """
    基于预测进行资源预留

    Args:
        predictions: 所有车辆的预测
        rsus: RSU列表
    """
    for future_slot in range(K):
        # 统计该时隙预测的任务数
        expected_tasks = sum(
            p['alpha'][future_slot] for p in predictions.values()
        )

        # 预留资源
        for rsu in rsus:
            rsu.reserve_resources(
                slot=future_slot,
                expected_load=expected_tasks / len(rsus)
            )
```
