实验数据不好时，严禁继续训练，必须立即叫停并展开讨论。

**Why:** 用户明确指出——数据不好依旧持续训练是浪费时间和资源。应当第一时间发现问题、分析原因、收敛方案后再继续。

**How to apply:**
1. 实验过程中，每当出现第一个完整结果时就检查是否符合预期
2. 如果不符合预期（如SAC差于PPO、violations反转等）→ **立即叫停实验进程**
3. 启动三博士辩论 → 向六教授答辩 → 收敛出唯一方案
4. 严格按收敛方案执行，禁止发散思维
5. 绝不"等更多seed看看"——1个seed确认异常就够叫停

这与"三博士+六教授辩论门禁"配合使用（见 feedback_three_phd_gate.md）。
