# 02 问题形式化与理论分析

本文档将系统模型转化为数学优化问题，并进行理论分析。

## 1. 决策变量定义

对于车辆 $i$ 在时隙 $k$，需要做出以下决策：

### 1.1 核心决策变量

| 变量 | 含义 | 取值范围 | 说明 |
|------|------|----------|------|
| $x_i(k)$ | 卸载决策 | $\{0, 1\}$ | 0=本地，1=卸载 |
| $a_i(k)$ | 目标RSU | $\mathcal{M}_i(k) \cup \{0\}$ | 0表示本地 |
| $f_i^{edge}(k)$ | RSU计算频率分配 | $[0, F_m^{max}]$ | 连续变量 |
| $B_i(k)$ | 带宽分配 | $[0, B_{total}]$ | 连续变量 |
| $\phi_i$ | 相位偏移量 | $[0, T_{check})$ | 一次性分配 |

### 1.2 决策变量的层次

```
┌─────────────────────────────────────────────────────────────┐
│                      决策变量层次结构                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  长期决策（系统初始化时）                                     │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  相位分配：φ_i for all i ∈ N                         │   │
│  │  决定各车辆的传输时刻偏移                              │   │
│  └─────────────────────────────────────────────────────┘   │
│                           ↓                                 │
│  短期决策（每时隙）                                          │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  卸载决策：x_i(k), a_i(k)                             │   │
│  │  决定是否卸载、卸载到哪个RSU                           │   │
│  └─────────────────────────────────────────────────────┘   │
│                           ↓                                 │
│  资源分配（每时隙，在卸载决策后）                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  资源分配：f_i^{edge}(k), B_i(k)                      │   │
│  │  在RSU上分配计算和通信资源                            │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 2. 优化目标

### 2.1 多目标优化问题

我们考虑一个多目标优化问题，目标是最小化长期平均代价：

$$\min_{\mathbf{X}, \mathbf{F}, \mathbf{B}, \boldsymbol{\phi}} \lim_{K \to \infty} \frac{1}{K} \sum_{k=1}^{K} \sum_{i=1}^{N} \left[ w_1 \cdot \bar{A}_i(k) + w_2 \cdot E_i(k) + w_3 \cdot \mathbb{1}[T_i(k) > T_i^{max}] \right]$$

其中：
- $\bar{A}_i(k)$：归一化AoI（除以目标AoI）
- $E_i(k)$：能耗
- $\mathbb{1}[T_i(k) > T_i^{max}]$：截止时间违反指示
- $w_1, w_2, w_3$：权重系数（满足 $w_1 + w_2 + w_3 = 1$）

### 2.2 分解为子目标

为了便于分析和优化，将目标分解为三个子目标：

#### 目标1：最小化平均AoI

$$J_1 = \lim_{K \to \infty} \frac{1}{K} \sum_{k=1}^{K} \sum_{i=1}^{N} A_i(k)$$

**含义**：保持感知信息的新鲜度

#### 目标2：最小化能耗

$$J_2 = \lim_{K \to \infty} \frac{1}{K} \sum_{k=1}^{K} \sum_{i=1}^{N} E_i(k)$$

**含义**：延长车载设备的电池寿命

#### 目标3：最大化任务完成率

$$J_3 = \lim_{K \to \infty} \frac{1}{K} \sum_{k=1}^{K} \sum_{i=1}^{N} \mathbb{1}[T_i(k) \leq T_i^{max}]$$

**含义**：确保任务在截止时间内完成

### 2.3 权重选择建议

| 场景 | $w_1$ (AoI) | $w_2$ (能耗) | $w_3$ (完成率) | 说明 |
|------|-------------|--------------|----------------|------|
| 安全优先 | 0.5 | 0.1 | 0.4 | 强调信息新鲜度和可靠性 |
| 能效优先 | 0.2 | 0.5 | 0.3 | 延长电池寿命 |
| 均衡 | 0.33 | 0.33 | 0.34 | 各目标平衡 |

## 3. 约束条件

### 3.1 截止时间约束

对于每个生成的任务，必须在截止时间内完成：

$$T_i^{total}(k) \leq T_i^{max}, \quad \forall i \in \mathcal{N}, \forall k \text{ where } \alpha_i(k) = 1$$

**展开形式**：

本地执行：
$$\frac{C_i(k)}{f_i^{local}} \leq T_i^{max}$$

卸载执行：
$$\frac{D_i(k)}{r_{i,m}(k)} + \frac{C_i(k)}{f_i^{edge}(k)} + \frac{D_i^{result}(k)}{r_{m,i}(k)} \leq T_i^{max}$$

### 3.2 RSU计算资源约束

每个RSU的计算资源有限：

$$\sum_{i: a_i(k) = m} f_i^{edge}(k) \leq F_m^{max}, \quad \forall m \in \mathcal{M}, \forall k$$

**含义**：卸载到同一RSU的任务共享其计算资源。

### 3.3 带宽资源约束

每个RSU的通信带宽有限：

$$\sum_{i: a_i(k) = m} B_i(k) \leq B_m^{total}, \quad \forall m \in \mathcal{M}, \forall k$$

**含义**：同时上传到同一RSU的车辆共享带宽。

### 3.4 覆盖约束

车辆只能卸载到覆盖范围内的RSU：

$$a_i(k) \in \mathcal{M}_i(k) \cup \{0\}, \quad \forall i \in \mathcal{N}, \forall k$$

**含义**：保证通信可达性。

### 3.5 能量预算约束（可选）

对于电池供电的车辆，长期能耗不超过预算：

$$\lim_{K \to \infty} \frac{1}{K} \sum_{k=1}^{K} E_i(k) \leq \bar{E}_i^{budget}, \quad \forall i \in \mathcal{N}$$

### 3.6 约束条件汇总

| 约束类型 | 数学表达 | 性质 |
|----------|----------|------|
| 截止时间 | $T_i(k) \leq T_i^{max}$ | 瞬时约束 |
| 计算资源 | $\sum f_i^{edge}(k) \leq F_m^{max}$ | 瞬时约束 |
| 带宽资源 | $\sum B_i(k) \leq B_m^{total}$ | 瞬时约束 |
| 覆盖约束 | $a_i(k) \in \mathcal{M}_i(k)$ | 瞬时约束 |
| 能量预算 | $\bar{E}_i \leq \bar{E}_i^{budget}$ | 长期约束 |

## 4. 完整问题形式化

### 4.1 问题P1（原始问题）

$$\textbf{P1:} \quad \min_{\mathbf{X}, \mathbf{A}, \mathbf{F}, \mathbf{B}, \boldsymbol{\phi}} \lim_{K \to \infty} \frac{1}{K} \sum_{k=1}^{K} \sum_{i=1}^{N} Cost_i(k)$$

$$\text{s.t.} \quad T_i^{total}(k) \leq T_i^{max}, \quad \forall i, k$$

$$\sum_{i: a_i(k) = m} f_i^{edge}(k) \leq F_m^{max}, \quad \forall m, k$$

$$\sum_{i: a_i(k) = m} B_i(k) \leq B_m^{total}, \quad \forall m, k$$

$$a_i(k) \in \mathcal{M}_i(k) \cup \{0\}, \quad \forall i, k$$

$$x_i(k) \in \{0, 1\}, \quad \forall i, k$$

$$f_i^{edge}(k), B_i(k) \geq 0, \quad \forall i, k$$

$$\phi_i \in [0, T_{check}), \quad \forall i$$

其中：
$$Cost_i(k) = w_1 \cdot \bar{A}_i(k) + w_2 \cdot E_i(k) + w_3 \cdot \mathbb{1}[T_i(k) > T_i^{max}]$$

### 4.2 问题特性分析

| 特性 | 说明 |
|------|------|
| 变量类型 | 混合（整数+连续） |
| 目标函数 | 非凸（包含指示函数） |
| 约束 | 线性约束 + 覆盖约束 |
| 时间耦合 | 有（长期平均优化） |
| 问题类别 | **混合整数非线性规划（MINLP）** |
| 复杂度 | **NP-hard** |

## 5. 问题复杂度分析

### 5.1 决策空间规模

**单时隙决策空间**：

- 卸载决策：每辆车2种选择（本地/卸载）
- RSU选择：每辆车最多 $M$ 个选择
- 总计：$O((2M)^N)$ 种组合

**多时隙决策空间**：

- $K$ 个时隙的总决策空间：$O((2M)^{NK})$

### 5.2 NP-hard严格证明

**定理（NP-hard性质）**：问题P1是NP-hard的。

**证明方法**：通过将已知的NP-hard问题——**广义分配问题 (Generalized Assignment Problem, GAP)** 归约到问题P1的简化版本。

**证明思路**：
1. 考虑P1在单一时隙、强制卸载的简化版本P1'
2. 将GAP实例中的任务映射为V2X车辆，代理映射为RSU
3. GAP的资源容量约束对应RSU的计算能力约束
4. GAP的最优解与P1'的最优解等价
5. 由于GAP是NP-hard的，因此P1'也是NP-hard的
6. P1'是P1的特例，故P1也是NP-hard的

**详细证明**：请参见 [附录A：NP-hard证明](./02.1_附录A_NP-hard证明.md)

**关键难点**：
1. **整数变量**：卸载决策 $x_i(k) \in \{0,1\}$ 是离散的
2. **时间耦合**：长期平均优化导致时隙间相互依赖
3. **资源竞争**：多车辆共享RSU的计算和通信资源
4. **非凸目标**：包含指示函数 $\mathbb{1}[T_i(k) > T_i^{max}]$

### 5.3 求解策略

由于原问题NP-hard，我们采用以下策略：

```
┌─────────────────────────────────────────────────────────────┐
│                      求解策略                                │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  策略1：问题分解                                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  将P1分解为多个子问题：                               │   │
│  │  - 相位分配问题（一次性，启动时）                      │   │
│  │  - 卸载决策问题（每时隙）                             │   │
│  │  - 资源分配问题（每时隙，给定卸载决策后）             │   │
│  └─────────────────────────────────────────────────────┘   │
│                           ↓                                 │
│  策略2：Lyapunov优化                                        │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  将长期约束转化为虚拟队列                             │   │
│  │  通过最小化漂移加惩罚实现在线决策                      │   │
│  │  有理论性能保证                                       │   │
│  └─────────────────────────────────────────────────────┘   │
│                           ↓                                 │
│  策略3：凸优化                                              │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  资源分配子问题是凸优化                               │   │

│  └─────────────────────────────────────────────────────┘   │
```

## 6. Lyapunov优化框架

### 6.1 基本思想

**核心思想**：将长期约束转化为虚拟队列，通过最小化"漂移加惩罚"函数实现在线决策。

**优势**：
- 无需知道未来信息
- 有理论性能保证
- 计算复杂度低

### 6.2 虚拟队列设计

**队列1：AoI队列**

跟踪每辆车的AoI与目标AoI的偏差：

$$Q_i^{AoI}(k+1) = \max\{0, Q_i^{AoI}(k) + A_i(k) - A_{target}\}$$

其中 $A_{target}$ 是目标AoI（如200ms）。

**队列2：能耗队列**

跟踪能耗与预算的偏差：

$$Q_i^{E}(k+1) = \max\{0, Q_i^{E}(k) + E_i(k) - \bar{E}_{budget}\}$$

**队列3：截止时间违反队列**

跟踪截止时间违反情况：

$$Q_i^{D}(k+1) = \max\{0, Q_i^{D}(k) + \mathbb{1}[T_i(k) > T_i^{max}] - \epsilon\}$$

其中 $\epsilon$ 是容忍的违反率（如0.05）。

### 6.3 Lyapunov函数

定义Lyapunov函数为所有虚拟队列的二次和：

$$L(\mathbf{Q}(k)) = \frac{1}{2} \sum_{i=1}^{N} \left[ (Q_i^{AoI}(k))^2 + (Q_i^{E}(k))^2 + (Q_i^{D}(k))^2 \right]$$

### 6.4 条件Lyapunov漂移

$$\Delta(\mathbf{Q}(k)) = \mathbb{E}[L(\mathbf{Q}(k+1)) - L(\mathbf{Q}(k)) | \mathbf{Q}(k)]$$

### 6.5 漂移加惩罚函数

$$\Delta(\mathbf{Q}(k)) + V \cdot \mathbb{E}[Cost(k) | \mathbf{Q}(k)]$$

其中 $V > 0$ 是控制参数。

### 6.6 在线决策原则

**定理（漂移加惩罚界）**：

每个时隙最小化以下表达式即可获得接近最优的长期性能：

$$\min_{\mathbf{x}(k), \mathbf{a}(k)} \sum_{i=1}^{N} \left[ V \cdot Cost_i(k) + Q_i^{AoI}(k) \cdot A_i(k) + Q_i^{E}(k) \cdot E_i(k) + Q_i^{D}(k) \cdot \mathbb{1}[T_i(k) > T_i^{max}] \right]$$

## 7. 理论性能分析

### 7.1 性能界定理

**定理1（性能界）**：

设最优长期平均代价为 $Cost^*$，则Lyapunov算法的长期平均代价满足：

$$\lim_{K \to \infty} \frac{1}{K} \sum_{k=1}^{K} \mathbb{E}[Cost(k)] \leq Cost^* + \frac{B}{V}$$

其中 $B$ 是与系统参数相关的常数：

$$B = \frac{1}{2} \sum_{i=1}^{N} \left[ (A_{max})^2 + (E_{max})^2 + 1 \right]$$

**证明思路**：
1. 利用漂移加惩罚的上界
2. 对时隙求和并取期望
3. 利用队列稳定性条件

### 7.2 队列稳定性定理

**定理2（队列稳定性）**：

虚拟队列是均值速率稳定的，即：

$$\lim_{K \to \infty} \frac{\mathbb{E}[Q(K)]}{K} = 0$$

**含义**：长期约束渐近满足。

### 7.3 延迟-代价权衡

**定理3（权衡关系）**：

平均队列长度（反映响应延迟）满足：

$$\lim_{K \to \infty} \frac{1}{K} \sum_{k=1}^{K} \mathbb{E}[\|\mathbf{Q}(k)\|] \leq \frac{B + V \cdot (Cost^* - Cost_{min})}{ε}$$

**解读**：
- $V$ 越大，长期代价越接近最优，但队列越长（响应越慢）
- $V$ 越小，响应越快，但代价偏离最优

### 7.4 参数V的选择

| V值 | 代价偏离 | 响应延迟 | 推荐场景 |
|-----|----------|----------|----------|
| 小（1-10） | 大 | 小 | 实时性要求高 |
| 中（10-100） | 中 | 中 | 一般场景 |
| 大（100-1000） | 小 | 大 | 优化代价为主 |

**经验公式**：
$$V = O(\sqrt{K})$$

可以在代价和延迟之间取得平衡。

## 8. 相位对齐的理论分析

### 8.1 同步拥塞问题

**问题描述**：

当所有车辆的检查周期相同且相位对齐时，会产生周期性的流量峰值。

**数学描述**：

设 $n$ 辆车，任务生成概率为 $p$，未对齐时某时隙的任务数量：

$$N_{sync}(k) = \sum_{i=1}^{n} \alpha_i(k)$$

期望：$\mathbb{E}[N_{sync}] = np$

方差：$\text{Var}[N_{sync}] = np(1-p)$

### 8.2 相位对齐效果

**定理4（峰值负载降低）**：

设有 $n$ 辆车，原始峰值负载为 $n$（最坏情况，所有车同时传输）。

采用均匀相位分配后，峰值负载期望降低为：

$$\mathbb{E}[\text{Peak}_{aligned}] = \frac{np}{n} \cdot n = np$$

但峰值方差显著降低：

$$\text{Var}[\text{Peak}_{aligned}] \approx \frac{np(1-p)}{n}$$

**直观解释**：流量从"脉冲式"变为"均匀式"。

### 8.3 相位分配的最优性

**定理5（均匀分配最优性）**：

在任务生成概率相同的情况下，均匀相位分配最小化峰值负载的期望。

**证明**：利用凸优化的对称性。

## 9. 预测增益的理论分析

### 9.1 预测对性能的影响

**定理6（预测增益界）**：

设预测窗口为 $K$，预测误差为 $\epsilon$，则预测式卸载相比反应式卸载的性能提升满足：

$$\text{Improvement} \geq (1 - \epsilon) \cdot \frac{K-1}{K} \cdot \alpha$$

其中 $\alpha$ 是任务时序相关系数。

**含义**：
- 预测越准确（$\epsilon$ 越小），增益越大
- 预测窗口越长（$K$ 越大），增益越大
- 任务相关性越强（$\alpha$ 越大），增益越大

### 9.2 事件触发模型的可预测性

**定理7（触发时刻可预测性）**：

对于匀速行驶的车辆，下一次任务触发时刻的预测误差：

$$\mathbb{E}[|k_{next}^{pred} - k_{next}^{actual}|] \leq \frac{\sigma_v}{v} \cdot \frac{\Delta p_{th}}{T_{check}}$$

其中 $\sigma_v$ 是速度标准差。

**含义**：速度越稳定，预测越准确。
