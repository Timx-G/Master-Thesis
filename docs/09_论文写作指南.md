## 3. Abstract 写作

### 3.1 结构（IMRD）

```
- Issue (问题背景): 1-2句
- Method (方法): 2-3句
- Results (结果): 1-2句
- Discussion (意义): 1句
```

### 3.2 示例模板

```
[Issue] Cooperative Perception Message (CPM) processing in Vehicle-to-Everything
(V2X) networks generates event-triggered periodic computation tasks with strict
latency requirements. Existing computation offloading methods, designed for
sporadic or Poisson-arrival tasks, fail to exploit the inherent periodicity,
leading to synchronization congestion and suboptimal resource utilization.

[Method] This paper proposes a Phase-Aligned Predictive Offloading (PAPO)
framework for periodic CPM task processing in vehicular edge computing.
First, we establish an event-triggered periodic task model based on ETSI
CPM standards and formulate a multi-objective optimization problem minimizing
Age of Information (AoI), energy consumption, and deadline violation rate.
Second, we design a phase alignment algorithm to distribute task arrivals
and avoid synchronization congestion. Third, we develop a Lyapunov-based
online algorithm with predictive resource allocation and proactive service
migration.

[Results] Extensive simulations demonstrate that PAPO reduces average AoI
by 35%, energy consumption by 28%, and improves task completion rate by 15%
compared to state-of-the-art baselines.

[Discussion] This work provides the first comprehensive framework for
exploiting task periodicity in vehicular edge computing.
```

### 3.3 关键词

```
Keywords: Mobile Edge Computing, Vehicle-to-Everything, Cooperative Perception,
Periodic Task Offloading, Age of Information, Lyapunov Optimization
```

### 4.2 写作模板

**Paragraph 1 - 大背景**
```
Vehicle-to-Everything (V2X) communication is a cornerstone technology for
connected and autonomous vehicles, enabling real-time information exchange
among vehicles, infrastructure, and pedestrians [1]. Among various V2X
applications, Cooperative Perception (CP) has emerged as a critical service
that allows vehicles to share sensor data and extend their perception range
beyond line-of-sight limitations [2]. The European Telecommunications
Standards Institute (ETSI) has standardized the Cooperative Perception
Message (CPM) format in TS 103 324, which defines periodic message
generation triggered by kinematic events [3].
```

**Paragraph 2 - 具体问题**
```
CPM processing imposes significant computational demands on vehicles due to
the need for real-time sensor fusion and object detection. Mobile Edge
Computing (MEC) provides a promising solution by offloading computation
tasks to nearby Road Side Units (RSUs) equipped with edge servers [4].
However, CPM tasks exhibit unique event-triggered periodic characteristics:
a new message is generated whenever the position change exceeds 4 meters,
speed change exceeds 0.5 m/s, or heading change exceeds 4 degrees, with a
maximum interval of 1 second [3]. This periodicity fundamentally differs
from the sporadic or Poisson-arrival assumptions in existing offloading
literature.
```

**Paragraph 3 - 现有方法局限性**
```
Existing computation offloading methods face three key challenges when
applied to periodic CPM tasks. First, most methods assume Poisson task
arrivals [5,6], which leads to inaccurate resource reservation and
increased queuing delays. Second, without proper coordination, periodic
tasks from multiple vehicles may synchronize and create burst arrivals,
causing severe congestion at edge servers [7]. Third, vehicle mobility
requires seamless service migration across RSUs, but existing approaches
lack integration between periodicity-aware scheduling and migration
decisions [8].
```

**Paragraph 4 - 本文贡献**
```
To address these challenges, this paper proposes a Phase-Aligned Predictive
Offloading (PAPO) framework. The main contributions are summarized as follows:

• We establish an event-triggered periodic task model for CPM processing
  based on ETSI standards and formulate a multi-objective optimization
  problem considering AoI, energy consumption, and deadline constraints.

• We design a phase alignment algorithm that distributes task generation
  phases to avoid synchronization congestion, reducing peak load by up to
  40% without affecting individual task deadlines.

• We develop a Lyapunov-based online algorithm that jointly optimizes
  offloading decisions, resource allocation, and service migration with
  provable performance bounds.

• We implement a hybrid prediction module combining kinematic models and
  neural networks to accurately forecast task arrivals 2-3 periods ahead.

• Extensive simulations based on realistic V2X scenarios demonstrate that
  PAPO achieves 35% lower AoI and 28% lower energy consumption compared
  to state-of-the-art baselines.
```

**Paragraph 5 - 论文组织**
```
The remainder of this paper is organized as follows. Section II reviews
related work. Section III presents the system model. Section IV formulates
the optimization problem. Section V describes the proposed algorithm.
Section VI presents simulation results. Section VII concludes the paper.
```

## 7. Algorithm 写作

### 7.1 算法伪代码规范

```latex
\begin{algorithm}[t]
\caption{Phase-Aligned Predictive Offloading (PAPO)}
\label{alg:papo}
\begin{algorithmic}[1]
\REQUIRE Vehicle set $\mathcal{V}$, RSU set $\mathcal{R}$, control parameter $V$
\ENSURE Offloading decisions $\{x_i\}$, resource allocation $\{\alpha_i, f_i\}$
\STATE \textbf{Initialization:} $Q_{aoi}(0) = Q_E(0) = Q_D(0) = 0$
\FOR{each time slot $t = 1, 2, \ldots, T$}
    \STATE // Phase 1: Predict task arrivals
    \STATE $\hat{\mathcal{K}}_t \gets$ \textsc{PredictTasks}$(t)$
    \STATE // Phase 2: Phase alignment
    \STATE $\{\phi_i\} \gets$ \textsc{AlignPhases}$(\hat{\mathcal{K}}_t)$
    \STATE // Phase 3: Lyapunov optimization
    \FOR{each task $k \in \mathcal{K}_t$}
        \STATE Compute $\Delta_k^{local}$ and $\Delta_k^{offload}$ by (\ref{eq:drift})
        \IF{$\Delta_k^{offload} < \Delta_k^{local}$}
            \STATE $x_k \gets 1$ (offload)
        \ELSE
            \STATE $x_k \gets 0$ (local)
        \ENDIF
    \ENDFOR
    \STATE // Phase 4: Resource allocation
    \STATE $\{\alpha_i^*, f_i^*\} \gets$ \textsc{ConvexSolve}$(\mathcal{K}_t^{off})$
    \STATE // Phase 5: Migration decision
    \STATE $\{m_i\} \gets$ \textsc{MigrationDecision}$(\mathcal{V}, \mathcal{R})$
    \STATE // Update virtual queues
    \STATE Update $Q_{aoi}(t+1), Q_E(t+1), Q_D(t+1)$ by (\ref{eq:queue})
\ENDFOR
\end{algorithmic}
\end{algorithm}
```

### 7.2 复杂度分析写法

```
The computational complexity of PAPO is analyzed as follows.
The phase alignment step requires $O(|\mathcal{V}| \cdot K)$ operations
where $K$ is the maximum number of periods considered.
The Lyapunov optimization step has complexity $O(|\mathcal{K}_t|)$ per
task, and the convex resource allocation requires $O(|\mathcal{K}_t|^3)$
using interior-point methods. The overall per-slot complexity is
$O(|\mathcal{V}| \cdot K + |\mathcal{K}_t|^3)$.
```

### 7.3 理论分析写法

```
\begin{theorem}
(Performance Bound) Under the PAPO algorithm, the time-averaged AoI,
energy consumption, and deadline violation rate satisfy:
\begin{equation}
\limsup_{T \to \infty} \frac{1}{T} \sum_{t=1}^{T} \mathbb{E}[g(t)]
\leq g^* + \frac{B}{V}
\end{equation}
where $g^*$ is the optimal value, $V$ is the control parameter, and
$B$ is a constant depending on system parameters.
\end{theorem}
```

## 11. 常见审稿意见及回复

### 11.1 常见问题

**Q1: 为什么不用DRL？**
```
Response: While DRL has been widely adopted for offloading decisions,
we chose Lyapunov optimization for three reasons: (1) DRL requires
extensive training and may not generalize well to varying vehicle
densities; (2) Lyapunov optimization provides theoretical performance
guarantees (Theorem 1); (3) Our approach has lower computational
complexity (O(n^3) vs O(n) per step, but DRL requires offline training).
We have added a comparison with DQN-based offloading in Section VI-E.
```

**Q2: 仿真是否足够realistic？**
```
Response: Thank you for this valuable comment. We have enhanced the
simulation setup: (1) Vehicle mobility now follows the SUMO simulator
with realistic traffic patterns; (2) Channel models are updated to
3GPP TR 37.885 V2X specifications; (3) CPM generation follows the
exact ETSI TS 103 324 standard. These details are now included in
Section VI-A.
```

**Q3: 相位对齐是否实际可行？**
```
Response: Phase alignment is practically feasible through the following
mechanisms: (1) RSUs can broadcast recommended phase offsets via
periodic beacon messages; (2) Vehicles adjust their CPM generation
timing within the allowed tolerance (≤50ms); (3) The adjustment is
transparent to upper-layer applications as it does not affect message
content or semantics. We have added implementation details in Section V-A.
```
