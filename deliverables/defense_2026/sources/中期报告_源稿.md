## 摘要

本研究面向多无人机全频复用上行 NOMA-MEC 网络中的时限任务处理问题，研究用户关联、NOMA 配对、跨无人机同频干扰、任务卸载和边缘算力分配之间的耦合关系。研究以绝对截止时刻前完成的唯一任务数量为核心目标，在满足用户唯一服务、资源块容量、接收功率顺序、硬 SIC 门限、合法无线速率和单无人机 MEC CPU 预算等约束的条件下，联合优化用户实际服务无人机、子载波、NOMA 角色、任务卸载比例和边缘计算资源。

围绕上述问题，已形成两项可独立验证并可组合运行的算法研究内容。第一，提出干扰外部性感知的跨无人机关联配对算法 IEA-CAP，通过 Replace、Position 和 CrossUAV 三类邻域联合调整服务归属与 NOMA 配对，并对每个候选调度重新计算实际服务信道、跨无人机干扰、SIC 可行性和服务器负载。第二，提出截止时间驱动的最小成本准入分配算法 DD-MCAA，从截止时间约束解析推导任务的最小卸载比例和最小 MEC CPU 需求，并在服务器预算内选择最大完成任务集合。两项方法共同构成外部性感知与截止时间驱动的联合调度资源分配算法 EAD-JSRA。

目前已完成系统建模、算法设计、仿真实现、基线与消融实验、统计分析及约束验证。50 个未见随机种子的确认性实验表明，EAD-JSRA 的平均按时完成率为 98.11%，95% 置信区间为 [97.94%, 98.26%]；相对预声明强基线 ExchangeStable 的配对平均增益为 0.1907 个百分点，95% 置信区间为 [0.1304, 0.2567]。IEA-CAP 中 CrossUAV 邻域和全网接受准则的独立贡献分别为 0.0487 和 0.1179 个百分点，置信区间均严格大于 0；DD-MCAA 相对 Crossing/Equal 策略提高 8.6898 个百分点，95% 置信区间为 [8.3736, 9.0106]。正式实验未出现任务重复服务、SIC 违规和 CPU 预算违规；在当前正式配置下，调度运行时间 P95 为 40.93 ms。阶段性结果表明，研究已完成从模型、算法到确认性证据的主要技术闭环，具备继续完成学位论文、学术论文和毕业答辩的基础。

**关键词：** 多无人机；移动边缘计算；上行 NOMA；干扰外部性；截止时间；任务卸载；资源分配

## 一、研究内容简介

### （一）研究背景与研究问题

随着物联网、智能巡检、应急通信和工业互联网等业务的发展，移动终端产生了大量计算密集型和时延敏感型任务。受终端处理能力和电池容量限制，仅依靠本地计算难以满足实时业务需求。移动边缘计算通过在网络边缘部署计算资源，使终端能够将部分或全部任务卸载至边缘服务器执行，从而降低处理时延并减轻终端计算压力。

在灾害救援、临时热点、偏远地区覆盖和无人化巡检等场景中，固定地面基础设施可能存在覆盖不足、部署周期长或受损失效等问题。无人机具有部署灵活、视距传播概率高和服务范围可调等特点，将 MEC 服务器搭载于无人机平台，可以快速构建空中通信与计算节点。多无人机协同能够扩大覆盖范围，但同时引入用户关联、频谱复用、跨无人机干扰和边缘算力竞争等多维耦合问题。

在全频复用条件下，不同无人机在相同子载波上接收用户信号。一个用户改变服务无人机、子载波或 NOMA 配对关系后，不仅会改变自身的服务信道，还会改变其他无人机接收端受到的同频干扰、NOMA 解码顺序和 MEC 服务器负载。因此，用户关联、子载波分配、NOMA 配对和计算资源分配不能被视为相互独立的局部决策。

另一方面，周期性采集、巡检分析、目标识别和应急信息处理等任务通常具有明确的到达时刻与截止时刻。吞吐量、平均时延或平均能耗不能直接反映每个任务能否按时完成。当多个任务竞争有限的无人机 MEC 算力时，还需要根据任务数据量、计算量、无线速率和剩余时限确定卸载比例、最低计算资源需求和任务准入顺序。

基于上述背景，本研究拟解决的核心问题是：在多无人机全频复用 NOMA-MEC 网络中，如何在统一的物理与计算约束下处理跨接收端干扰外部性和时限任务资源竞争，并在有限调度时间内尽可能提高任务按时完成率。

### （二）研究对象、目标与边界

研究对象为固定悬停的多无人机上行 NOMA-MEC 网络。多架无人机搭载边缘服务器并复用相同子载波，每个无人机—子载波资源块最多接入两名 NOMA 用户。终端任务支持连续部分卸载，本地计算分支与边缘计算分支并行执行。

每个任务具有唯一任务标识、到达时刻 \(a_i\) 和绝对截止时刻 \(d_i^{\mathrm{abs}}\)，其相对时限预算为

\[
T_i=d_i^{\mathrm{abs}}-a_i>0.
\]

任务按时完成当且仅当

\[
a_i+\tau_i\leq d_i^{\mathrm{abs}},
\]

其中，\(\tau_i\) 为任务从到达到本地或边缘计算完成的总时延。研究的首要目标是最大化按时完成的唯一任务数，次级目标依次为改善已完成任务的截止裕量、降低跨无人机同频干扰并获得确定性代表解。

研究约束包括用户唯一服务、资源块容量、接收功率顺序、硬 SIC 门限、合法有限速率以及每架无人机的 MEC CPU 预算。当前研究边界为固定悬停、等功率上行、集中式 CSI 和连续部分卸载；无人机轨迹、功率控制、电池消耗、分布式 CSI、跨无人机 CPU 迁移和长期任务队列不作为本阶段的核心优化变量。上述边界用于保证两项创新能够被独立实现和严格验证，并将在学位论文局限性部分予以说明。

### （三）研究内容一：干扰外部性感知的跨无人机关联配对方法

针对多无人机全频复用条件下用户关联与 NOMA 配对相互耦合的问题，研究设计干扰外部性感知的跨无人机关联配对算法 IEA-CAP。

首先，建立显式调度对象，统一记录用户的实际服务无人机、子载波位置和 NOMA 解码角色。调度对象作为关联关系的唯一来源，信道计算、干扰计算、SIC 检查和服务器负载均从同一调度对象读取服务归属，避免服务无人机、信道来源和计算服务器之间出现语义不一致。每个任务只允许出现在一个调度位置，以保证任务身份和完成统计的唯一性。

其次，在约束可行的初始调度基础上，设计 Replace、Position 和 CrossUAV 三类邻域操作。Replace 操作用未调度用户替换当前调度用户；Position 操作在同一无人机内部调整子载波位置或 NOMA 角色；CrossUAV 操作改变用户的实际服务无人机，并同步修复资源容量、用户唯一性和强弱用户角色。

对于每个候选调度，算法按照实际服务无人机重新计算接收信号功率、跨无人机同频干扰、NOMA 解码顺序、SIC 可行性、无线传输速率和 MEC 服务器负载。候选评价不复用原调度中的旧信道或旧干扰结果，从而保证跨无人机关联变化能够完整反映到物理层和计算层。

候选接受采用确定性全网字典序目标，首先比较按时完成任务数，在完成任务数相同时依次比较任务截止裕量、跨无人机干扰和稳定调度编码。算法按照固定顺序枚举候选，仅接受使全网目标严格改善的首个候选。由于可行调度集合有限且不接受相同或更差的调度，搜索过程能够有限终止。算法输出只保证给定 Replace、Position 和 CrossUAV 邻域下的局部最优，不作一般规模全局最优声明。

### （四）研究内容二：截止时间驱动的卸载与 MEC 算力分配方法

针对多个时限任务竞争有限 MEC 算力的问题，研究设计截止时间驱动的最小成本准入分配算法 DD-MCAA。

设任务数据量为 \(D_i\)，计算量为 \(C_i\)，本地 CPU 频率为 \(f_i^{\mathrm{loc}}\)，无线传输速率为 \(R_i\)，结果返回比例为 \(\rho\)。根据本地计算分支的截止时间约束，可以得到任务按时完成所需的最小卸载比例

\[
\alpha_i^{\min}=\max\left(0,1-\frac{T_if_i^{\mathrm{loc}}}{C_i}\right).
\]

进一步考虑上传、边缘执行和结果返回时延，可得到任务所需的最小 MEC CPU 资源

\[
f_i^{\min}=\frac{\alpha_i^{\min}C_i}{T_i-\alpha_i^{\min}(1+\rho)D_i/R_i}.
\]

当无线速率非法、上述分母非正、最小卸载比例不合法或最低 CPU 需求超过服务器预算时，任务在当前无线调度下被判定为不可行。对于其余任务，算法按照 \((f_i^{\min},\mathrm{task\_id})\) 进行稳定升序排列，并在每架无人机的 CPU 预算内选择能够容纳的最长任务前缀。

在任务价值相同、CPU 成本可加和单无人机硬 CPU 预算等条件下，最小成本最长前缀能够获得最大完成任务数。完成准入后，算法使用统一时延函数重新计算任务的本地计算、上传、边缘执行和结果返回时延，以复核最终完成集合，保证解析推导、资源分配和实验评价采用一致的完成判定口径。

### （五）总体算法与技术路线

IEA-CAP 与 DD-MCAA 共同构成外部性感知与截止时间驱动的联合调度资源分配算法 EAD-JSRA。在总体算法中，DD-MCAA 不是无线调度结束后的独立后处理模块，而是嵌入每个 IEA-CAP 候选的完整评价内部。

总体技术路线为：生成统一任务与信道快照；构建约束可行的显式初始调度；利用 IEA-CAP 枚举关联和配对候选；重新计算实际服务信道、跨无人机干扰、NOMA 速率与 SIC；调用 DD-MCAA 计算任务级最小资源需求和完成集合；根据全网字典序目标决定接受或拒绝候选；最终输出任务完成记录、调度结果和资源分配结果。

## 二、研究工作进展

### （一）系统模型与统一评价机制

目前已完成任务、用户、信道、无人机、子载波、NOMA 角色、卸载比例和 MEC CPU 的统一建模。每个任务具有唯一任务标识、到达时刻和绝对截止时刻，失败任务不跨时隙重复进入统计分母。用户实际服务无人机由显式调度对象唯一确定，无线速率、跨无人机干扰、SIC 检查和服务器负载均按照实际服务归属计算。

已建立统一评价机制，主算法和所有对比方法使用相同的物理层、任务完成判定、SIC 规则和 CPU 预算检查。不同方法在相同随机种子下读取完全一致的任务与信道轨迹，从实验设计层面排除外生输入差异对对比结果的影响。

### （二）IEA-CAP 算法实现与验证

已完成约束可行的调度初始化、确定性 SIC 修复、Replace 邻域、Position 邻域、CrossUAV 邻域、候选全网重评价和字典序首次改进搜索。CrossUAV 操作改变用户服务归属后，系统能够同步更新目标接收端信道、其他无人机同频干扰、NOMA 解码顺序、SIC 可行性和服务器负载。

为分离 IEA-CAP 中两个组成部分的独立贡献，已构建 Intra/CrossUAV 与 Bilateral/Global 两个维度的严格 \(2\times2\) 消融。四组实验共享相同任务轨迹、信道、初始化方法、资源分配器和最终评价器，仅切换邻域范围与候选接受准则。

### （三）DD-MCAA 算法实现与理论验证

已完成剩余时限计算、最小卸载比例推导、最小 MEC CPU 计算、不可行任务筛选、稳定最小成本排序、CPU 最长前缀准入和统一时延复核等模块。

已通过交换论证分析最小成本最长前缀的最大基数性质，并在小规模任务集合上利用完整子集枚举进行复核。理论结论严格限定于任务价值相同、CPU 成本可加和单无人机硬 CPU 预算等条件，不推广至有权任务、跨无人机 CPU 迁移或长期队列问题。

### （四）实验平台与证据管理

已完成配置驱动的仿真实验平台，实现任务与信道轨迹生成、算法运行、约束检查、结果汇总、统计分析和自动制图。实验产物包含实验配置、随机种子、结果摘要、统计推断和校验信息，可对论文和答辩中使用的性能数字进行来源追溯。

现有自动化验证覆盖任务唯一性、服务信道一致性、SIC、CPU 预算、算法终止、配对实验一致性、统计分析和实验产物完整性。正式材料记录的自动化测试数量为 257 项，正式实验设定的 7 项验收门禁均已通过。

### （五）实验目的与研究假设

阶段性实验主要验证以下研究假设：第一，EAD-JSRA 在相同任务轨迹、信道条件和资源约束下能够取得高于预声明强基线 ExchangeStable 的按时完成率；第二，在保持初始化、接受准则和资源分配器一致时，CrossUAV 邻域能够产生独立且方向稳定的改善；第三，在保持邻域范围和资源分配器一致时，全网接受准则能够优于仅考虑局部参与者收益的双边接受准则；第四，在相同无线调度下，DD-MCAA 能够显著提高有限 CPU 预算内的任务按时完成率；第五，算法能够满足任务唯一性、资源块容量、硬 SIC 和 CPU 预算约束，并在可接受时间内完成调度。

### （六）确认性实验协议与统计方法

确认性实验采用 50 个未参与算法开发和参数调整的随机种子，种子编号为 1000—1049。每个随机种子运行 100 个时隙，正式基本配置为用户数 \(N=20\)、无人机数 \(K=2\)、每架无人机子载波数 \(S=3\)。所有方法使用相同的任务与信道轨迹、物理层参数、SIC 规则、CPU 预算和任务分母。

主评价指标为按时完成率

\[
\eta_{\mathrm{on\text{-}time}}=\frac{N_{\mathrm{on\text{-}time}}}{N_{\mathrm{arrived}}},
\]

其中，\(N_{\mathrm{on\text{-}time}}\) 为绝对截止时刻前完成的唯一任务数，\(N_{\mathrm{arrived}}\) 为到达系统的唯一任务总数。

统计推断以随机种子为配对单位。对方法间按时完成率差值计算配对 bootstrap 95% 置信区间，采用 Wilcoxon 符号秩检验判断配对差值是否系统性偏离 0，使用 Holm 方法控制多重比较的第一类错误，并报告秩二列效应量。实验结论分别讨论统计显著性和工程增益幅度，不以显著性代替实际效果大小。

### （七）总体算法对比结果

| 方法 | 按时完成率 | 与 EAD-JSRA 的差距 |
|---|---:|---:|
| Local-only | 43.94% | -54.17 个百分点 |
| Greedy | 94.86% | -3.24 个百分点 |
| Per-UAV ILP | 96.81% | -1.30 个百分点 |
| IA-Greedy | 97.61% | -0.49 个百分点 |
| Fair OFDMA | 97.52% | -0.58 个百分点 |
| ExchangeStable | 97.91% | -0.19 个百分点 |
| Intra-Global | 98.06% | -0.05 个百分点 |
| **EAD-JSRA** | **98.11%** | — |

EAD-JSRA 在 50 个未见随机种子上的平均按时完成率为 98.11%，95% bootstrap 置信区间为 [97.94%, 98.26%]。相对于预声明强基线 ExchangeStable，EAD-JSRA 的配对平均增益为 0.1907 个百分点，95% 置信区间为 [0.1304, 0.2567]，Holm 校正后 \(p=6.71\times10^{-6}\)，秩二列效应量为 0.869。

上述结果表明，EAD-JSRA 相对 ExchangeStable 的绝对增益有限，但配对差值置信区间严格大于 0，且在多数随机种子上保持一致的改善方向。因此，总体有效性假设获得统计支持，但不将该结果解释为相对强基线的大幅性能提升。相对于 Greedy 和 Per-UAV ILP，EAD-JSRA 分别提高约 3.24 和 1.30 个百分点，说明仅采用局部贪心决策或按无人机独立优化，难以充分处理跨无人机干扰与边缘算力之间的耦合关系。

### （八）IEA-CAP 严格消融结果

| 邻域范围 | 双边接受准则 | 全网接受准则 |
|---|---:|---:|
| Intra | 97.9146% | 98.0567% |
| CrossUAV | 97.9874% | **98.1054%** |

在全网接受准则保持不变的条件下，将邻域范围由 Intra 扩展为 CrossUAV 后，按时完成率由 98.0567% 提高至 98.1054%。CrossUAV 邻域的配对平均贡献为 0.0487 个百分点，95% 置信区间为 [0.0138, 0.0841]，Holm 校正后 \(p=0.0201\)，秩二列效应量为 0.521。该结果支持跨无人机邻域能够产生独立改善的研究假设。

在 CrossUAV 邻域保持不变的条件下，将双边接受准则替换为全网接受准则后，按时完成率由 97.9874% 提高至 98.1054%。全网接受准则的配对平均贡献为 0.1179 个百分点，95% 置信区间为 [0.0697, 0.1645]，Holm 校正后 \(p=0.000418\)，秩二列效应量为 0.709。该结果表明，仅扩展跨无人机候选范围不足以获得完整效果，还需要在候选评价中考虑动作对其他接收端和 MEC 服务器产生的全网影响。

IEA-CAP 两个组成部分的置信区间均严格大于 0，但绝对贡献分别约为 0.05 和 0.12 个百分点。其阶段性结论应表述为：在约 98% 的高完成率区域内，CrossUAV 邻域和全网接受准则仍能够产生方向稳定的独立改善；该方法的研究价值同时体现在实际服务信道一致性、跨接收端外部性处理、硬 SIC 约束满足和可解释消融设计，而非大幅性能增益。

### （九）DD-MCAA 独立实验结果

| 资源分配策略 | 按时完成率 |
|---|---:|
| Fixed-half/Equal | 76.13% |
| Crossing/Equal | 89.42% |
| **DD-MCAA** | **98.11%** |

在完全相同的无线调度条件下，DD-MCAA 相对 Crossing/Equal 的配对平均增益为 8.6898 个百分点，95% 置信区间为 [8.3736, 9.0106]，Holm 校正后 \(p<1.6\times10^{-14}\)，秩二列效应量为 1.0。

结果表明，将任务截止时间解析为最小卸载比例和最小 MEC CPU 需求，并按照最小资源成本执行任务准入，能够显著提高有限 CPU 预算下的任务完成数量。秩二列效应量为 1.0，说明在 50 个确认性随机种子中，DD-MCAA 相对 Crossing/Equal 的配对差值方向完全一致。该模块是当前总体算法性能改善的主要来源。

### （十）约束可行性、枚举参考与运行效率

| 检查项目 | 阶段性结果 |
|---|---:|
| 任务重复服务 | 0 |
| 非法资源块容量 | 0 |
| 服务无人机与信道来源不一致 | 0 |
| 最终调度 SIC 违规 | 0 |
| 无人机 CPU 预算违规 | 0 |
| 非法或非有限速率 | 0 |
| 搜索不收敛 | 0 |

正式主实验、IEA-CAP 消融和 DD-MCAA 消融均未出现任务唯一性、SIC 和 CPU 预算违规，说明阶段性性能改善并非通过放松系统硬约束获得。

在小规模配置下，对用户关联、子载波位置、NOMA 配对、SIC 可行性和资源准入组合进行了完整枚举。在已完成的 500 个小规模时隙中，EAD-JSRA 与枚举参考的完成任务数平均差距和最大差距均为 0。该结果属于已枚举小规模实例上的经验一致性证据，不构成一般规模全局最优证明。

在 \(N=20\)、\(K=2\)、\(S=3\) 的正式配置下，EAD-JSRA 的调度运行时间 P50 为 18.15 ms，P95 为 40.93 ms，低于预声明的 1 s 验收门槛。EAD-JSRA 的 Jain 用户按时完成公平性为 0.99945，平均 CPU 利用率为 34.33%。较高的公平性表明完成任务未明显集中于少数用户；CPU 利用率未达到饱和则说明任务失败不仅由总 CPU 容量决定，还受到无线信道、SIC、截止时间和任务最低资源需求的共同影响。

### （十一）阶段性成果与结论

目前已经形成统一系统模型、IEA-CAP、DD-MCAA、总体 EAD-JSRA、配置驱动仿真平台、严格消融方案、统计分析流程、约束审计机制和正式确认性实验结果。阶段性证据支持以下结论：EAD-JSRA 在统一实验协议下达到 98.11% 的按时完成率；相对强基线 ExchangeStable 的配对增益置信区间严格大于 0；IEA-CAP 的 CrossUAV 邻域和全网接受准则分别获得独立统计支持；DD-MCAA 产生 8.6898 个百分点的独立增益，是总体性能改善的主要来源；正式实验未发现硬约束违规；当前规模下运行时间满足预声明门槛。

上述结果表明，研究已经完成从问题定义、数学建模、算法实现到确认性验证的主要技术闭环，下一阶段工作的重点是深化理论表述与机制解释、补充外部有效性实验、完成学位论文和学术论文，并形成规范的毕业答辩材料。

## 三、下一步工作计划

### （一）完善理论分析与论文表达

下一阶段将进一步规范系统模型、变量、约束和目标函数，保证学位论文中的公式、算法伪代码和实现逻辑一致。重点补充 IEA-CAP 候选生成与可行性修复规则、字典序目标与确定性平局处理、有限终止性和局部最优边界；完善 DD-MCAA 最小卸载比例与最小 CPU 需求推导、最小成本最长前缀的交换论证以及理论适用条件；补充总体 EAD-JSRA 的伪代码、复杂度分析和两项创新的组合关系。

论文将严格区分理论证明、小规模枚举结果和一般规模经验结果，不使用超出证据边界的全局最优或实际部署结论。

### （二）加强 IEA-CAP 的机制证据

鉴于 IEA-CAP 相对强基线的绝对增益较小，后续研究不以反复调整参数扩大数字为主要目标，而是补充能够解释算法作用机制和适用条件的证据。计划统计 CrossUAV 候选的生成数量、可行比例和接受比例；分析接受动作前后的跨无人机干扰、SIC 状态和服务器负载变化；构造双边准则拒绝但全网准则接受的代表性案例；研究不同干扰强度、用户密度和服务器负载不均衡程度下两个组件的独立贡献。

通过上述分析，明确回答 IEA-CAP 的必要性、有效场景和性能边界，使创新点一的论证从单一平均指标扩展为统计证据、机制证据和约束正确性的综合支撑。

### （三）补充鲁棒性、扩展性与外部有效性实验

后续将进一步研究截止时间紧迫程度、任务数据量、任务计算量、用户空间密度、无人机 CPU 负载不均衡程度、CSI 误差、SIC 残差和噪声变化对算法性能的影响。规模扩展实验将覆盖不同用户数、无人机数和子载波数，并同步报告按时完成率、约束违规、CPU 利用率以及调度时间 P50/P95。

实验仍采用与研究模型一致的标准信道和任务轨迹，不强行引入场景不匹配的车辆或公交移动数据。为增强外部有效性，将在论文中完整说明参数来源、任务分布、随机种子和轨迹生成规则，并提供可复现实验配置，使其他研究者能够独立复核主要结论。

### （四）优化算法运行效率

针对候选调度全网重评价带来的计算开销，计划研究候选预筛选、无效动作剪枝和中间结果缓存。工程优化必须保持实际服务信道、跨无人机干扰、SIC 和最终时延评价口径不变，并通过回归实验验证优化前后任务完成结果的一致性。

同时继续记录不同网络规模下的运行时间分布，分析候选规模与算法开销之间的关系，明确集中式 EAD-JSRA 的适用规模和实时性边界。

### （五）撰写并投稿学术论文

计划围绕“面向时限任务的多无人机 NOMA-MEC 干扰感知调度与最小成本准入方法”撰写一篇学术论文。论文将包括统一系统模型、IEA-CAP、DD-MCAA、两项创新的独立消融、强基线配对统计、鲁棒性与扩展性分析以及方法适用边界。

学术论文投稿的主要作用是获得外部同行评价，增强研究成果的学术可信度，但不将论文录用等同于行业应用证明，也不将毕业进度完全依赖于期刊评审结果。投稿目标将结合论文成熟度、研究方向和评审周期，在移动边缘计算、无线资源管理、无人机通信或计算机仿真相关的中文核心、CSCD、EI 或 SCI 期刊中审慎选择。

### （六）形成专业学位工程成果

在算法和实验基础上，进一步整理可运行的 EAD-JSRA 仿真软件、统一实验配置、自动分析工具、软件设计说明、测试报告和复现说明，并结合学校与学院要求评估申请软件著作权的可行性。

如需形成行业层面的外部评价，将优先考虑企业导师或相关工程人员对应用场景、运行复杂度和部署边界的书面评价，或开展小规模联合测试。学术论文体现同行学术评价，软件著作权、测试报告和企业评价体现工程成果，三者的证明作用应予以区分。

### （七）完成学位论文与毕业答辩材料

按照学校模板完成论文摘要、目录、符号表、公式编号、算法伪代码、实验图表、参考文献和附录，统一论文题目、算法名称、实验数字与答辩材料的表述口径。开展论文自查、导师审阅和格式审查，重点检查创新点独立性、实验公平性、统计结论、适用边界和参考文献真实性。
