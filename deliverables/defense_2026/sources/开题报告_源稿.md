## 摘要

无人机搭载移动边缘计算（Mobile Edge Computing，MEC）服务器，可在灾害现场、临时大型活动、海洋物联网和地面基础设施覆盖不足区域快速构建低时延计算服务。非正交多址接入（Non-Orthogonal Multiple Access，NOMA）允许多个用户复用同一时频资源，能够缓解无人机链路频谱受限问题；但在多无人机全频复用场景中，用户关联、NOMA 配对、跨无人机同频干扰、串行干扰消除（Successive Interference Cancellation，SIC）和边缘算力分配相互耦合。若仍以单无人机或单小区方式局部决策，配对动作产生的干扰外部性可能使其他无人机的速率和任务完成状态同时变化；若仅优化平均时延或吞吐量，也不能直接保证更多独立任务在绝对截止时刻前完成。

针对上述工程矛盾，本课题研究固定悬停、全局信道状态信息可用、等功率上行、每子载波至多两用户的多无人机 NOMA-MEC 网络。主目标定义为最大化在绝对截止时刻前完成的唯一任务数，并采用本地计算与边缘计算并行的连续部分卸载模型。研究拟形成两个相互独立又可串联验证的创新模块：其一，构建单一显式调度对象，基于真实服务无人机重算接收功率、SIC 次序与跨无人机干扰，并利用 Replace、Position 和 CrossUAV 三类确定性邻域联合优化用户关联和配对；其二，从截止时间约束解析推导最小卸载比例及最小 MEC CPU 需求，将每架无人机上的任务选择转化为单位收益、可加成本的最大基数问题，以稳定的最小成本前缀获得预算内最大按时完成任务数。

本课题采用“统一外生轨迹—显式调度—解析资源分配—统一评估—canonical 产物”的可复现实验链路。实验将设置严格 2×2 配对消融、资源分配独立消融、增量分解、负控制、规模扩展、SIC 门限和 CSI 误差敏感性，以及小规模完整可行域枚举；确认性实验采用未见随机种子和配对统计检验。当前报告只给出可审计的模型、方法与实验协议，不预先宣称性能优势。

**关键词：** 多无人机；移动边缘计算；上行 NOMA；干扰外部性；用户关联与配对；截止时间；资源分配

## 1 研究背景与意义

### 1.1 工程背景

终端侧智能感知不断增加图像识别、目标检测、状态诊断和应急决策等计算密集型任务。受尺寸、能耗和散热约束，移动终端本地算力难以稳定满足严格时限；传统固定基站与云中心又可能受到回传时延、覆盖盲区或灾后基础设施损坏的影响。UAV-MEC 将计算能力部署到空中平台，具有快速部署、视距链路概率较高和服务位置可调整等特点，是专业硕士研究中兼具算法价值与工程实现价值的典型场景[1-3]。

单架无人机的覆盖和算力均有限，多无人机协同能够扩大服务区域，却会引入更强的无线与计算耦合。为提高频谱利用率，本课题让所有无人机复用同一组子载波，并在每个无人机—子载波上容纳至多两个上行 NOMA 用户。此时一个用户从 UAV A 迁移到 UAV B，不只是改变自己的服务链路，还会改变两个接收端上的同频干扰、NOMA 解码次序、SIC 可行性和 MEC 负载。因此，用户关联不能停留在初始化阶段，配对也不能只依据本地信道差异独立完成。

### 1.2 研究意义

**理论意义。** 本课题将跨接收端干扰外部性显式纳入联合关联与配对过程，并将非光滑的 deadline-met count 目标与解析资源需求连接起来。两个模块分别回答“怎样得到约束一致的无线调度”和“给定调度后怎样完成最多任务”，有助于澄清无线速率提升与端到端任务按时完成之间的区别。

**工程意义。** 课题强调单一状态语义、硬约束检查、确定性搜索和可追溯实验产物。算法输出可直接回答每个任务由哪架无人机服务、使用哪个子载波、为何被接纳或拒绝、需要多少边缘算力，有利于面向应急通信等场景进行运行日志审计和资源容量规划。

**专业学位价值。** 研究不仅给出公式和算法，还计划形成可执行的软件模块、配置驱动实验入口、逐任务记录、统计报告和校验清单，使“问题建模—算法实现—软件测试—实验验证—论文数字”形成闭环。该成果形态符合专业硕士对复杂工程问题分析、可实现方案设计及系统验证能力的要求。

## 2 国内外研究现状

### 2.1 UAV 辅助 MEC 与多无人机协同

MEC 通过将计算和存储能力下沉到网络边缘来降低传输与处理时延，已有综述从通信视角系统梳理了卸载决策、无线资源和边缘算力之间的耦合[1]。UAV 通信研究进一步说明，空中平台可利用视距链路和快速部署能力改善覆盖，但高度、路径损耗、能量和干扰管理必须联合考虑[2-3]。近年来，多无人机 MEC 研究已覆盖任务卸载、用户关联、轨迹和通信—计算资源联合优化[10-12]。这些工作为多节点协同提供了基础，但不少方法把轨迹或能耗作为主变量，或采用正交资源简化跨无人机干扰，不直接处理固定悬停、全频复用、两用户上行 NOMA 与独立任务截止时间同时存在的情形。

### 2.2 NOMA 用户分组与 SIC 约束

NOMA 通过功率域复用和 SIC 提高并发接入能力。相关综述、动态用户聚类以及子信道分配研究表明，用户信道差异、解码顺序、功率和资源分配会共同决定系统性能[4-6]。多载波 NOMA 的用户调度通常采用匹配、整数规划或交替优化；UAV 辅助上行 NOMA 也开始将用户分组与航迹、调度联合研究[9]。然而，单小区配对形成的偏好或收益在多接收端全频复用场景中不再局部：一个配对对其他 UAV 的 SINR 有直接影响，固定偏好列表难以表达这种外部性。

### 2.3 NOMA-MEC 卸载与计算资源分配

NOMA 与 MEC 的联合研究已考虑部分卸载、传输功率、子信道、时间和计算资源的协同优化[7-8,13]。现有目标多聚焦总能耗、加权时延、吞吐量或能量效率，常用连续优化、交替迭代或交换稳定分配求解。对于具有硬截止时间的独立任务，平均时延降低并不必然等价于完成任务数增加；把每个任务分配相同算力，也可能因少数高成本任务挤占预算而降低整体完成数。因此，需要从 deadline 约束直接推导每个任务的最小资源成本，再围绕完成任务数进行离散选择。

### 2.4 外部性感知匹配与可复现验证

匹配理论已用于用户—小区关联和无线资源分配。带外部性的匹配模型指出，一方的匹配会改变其他参与者的效用，因而需要在候选动作后更新真实系统状态和偏好[14]。这一思想适合刻画多 UAV 同频干扰，但仍需与物理层 SIC、服务归属及 MEC 预算共同验证。同时，随机仿真若让不同算法读取不同任务轨迹、重复统计失败任务，或从非版本化结果目录直接生成论文图表，会削弱结论可信度。本课题因此把实验可复现性视为方法的一部分，而不是后处理环节。

## 3 研究缺口与问题界定

### 3.1 现有方法的组合缺口

基于上述文献与前期原型审计，本课题关注以下尚未充分闭环的问题：

1. **服务归属与评价语义分离。** 若跨 UAV 交换已经改变实际服务节点，速率、干扰和 CPU 仍按初始最近 UAV 归属计算，算法评价对象会失真。
2. **SIC 约束与最终解分离。** 只在初始化阶段筛选 SIC 可行配对，而候选交换后不重新检查硬门限，不能保证最终调度可解码。
3. **无线目标与任务目标分离。** 提升和速率或降低平均时延不必然增加绝对截止时间前完成的唯一任务数。
4. **资源公式与网络预算分离。** 单任务时延平衡点不能直接解决多个任务在有限 MEC CPU 下的最大完成数选择。
5. **消融与统计对象不一致。** 若各方法初始化、轨迹、评价器或搜索预算不同，无法把差异归因于邻域或接受准则。
6. **结果与代码来源分离。** 缺少 manifest、逐任务记录和校验和时，论文数字无法回溯到唯一代码、配置和随机种子。

### 3.2 研究问题

在固定悬停的多 UAV NOMA-MEC 网络中，给定每个时隙的用户位置、任务参数和全局 CSI，联合决定：任务是否需要无线卸载、由哪架 UAV 服务、占用哪个子载波及其 NOMA 角色、卸载比例，以及 UAV 分配的 MEC CPU。研究的主问题是：

> 在用户唯一关联、每 UAV—子载波容量、上行 NOMA 解码次序、参数化 SIC 门限、跨 UAV 同频干扰和 MEC CPU 预算等约束下，如何最大化在绝对截止时刻前完成的独立任务数，并使结果可以从固定输入轨迹稳定复现？

### 3.3 研究边界

本课题保留固定悬停、等功率上行、集中式全局 CSI、每子载波至多两个 NOMA 用户、连续可分任务、本地与边缘并行执行、时隙内信道和任务参数不变等假设。UAV 轨迹优化、联合发射功率控制、分布式或缺失 CSI、真实飞行平台部署和深度强化学习改进不纳入本轮核心范围，只在局限性与未来工作中讨论。该边界有助于将研究资源集中在“跨 UAV 干扰下的调度语义”和“deadline 驱动的资源选择”两个核心矛盾上。

## 4 系统模型与优化问题

### 4.1 网络与调度模型

设 UAV 集合为 \(\mathcal K=\{1,\ldots,K\}\)，子载波集合为 \(\mathcal S=\{1,\ldots,S\}\)，当前时隙任务集合为 \(\mathcal I\)。每个 UAV 固定悬停并搭载容量为 \(F_k\) 的 MEC 服务器；所有 UAV 复用相同子载波集合。任务 \(i\) 对应用户 \(u_i\)，具有输入数据量 \(D_i\)、计算量 \(C_i\)、本地 CPU \(f_i^{\mathrm{local}}\)、到达时刻 \(a_i\) 和绝对截止时刻 \(d_i^{\mathrm{abs}}\)。二者确定任务可用的相对时延预算

\[
T_i=d_i^{\mathrm{abs}}-a_i>0.
\]

任务按时完成的统一判定是 \(a_i+\tau_i\le d_i^{\mathrm{abs}}\)，等价于 \(\tau_i\le T_i\)。后文所有 deadline 公式中的 \(T_i\) 均表示这一相对预算，而不是绝对时刻。

研究使用 \(\Pi\)（代码中为单一显式 `Schedule`）表示无线调度决策。每条调度记录包含 `task_id`、`user_id`、`serving_uav`、`subcarrier` 和 `noma_role`；其中角色为 `strong`、`weak` 或 `solo`。定义二元服务—子载波指示 \(x_{u,k,s}(\Pi)\in\{0,1\}\)：当且仅当调度 \(\Pi\) 将用户 \(u\) 分配给服务 UAV \(k\) 的子载波 \(s\) 时取 1。最近 UAV 只用于产生初始化候选池，实际服务归属、跨 UAV 干扰和 MEC 负载均由最终 \(\Pi\) 派生。

### 4.2 信道、噪声与 NOMA 速率

令 \(h_{i,k}\) 表示用户 \(i\) 到 UAV \(k\) 的功率信道增益，空地路径损耗采用明确标注的 Urban 概率视距模型[3]。系统从噪声功率谱密度和接收机噪声系数统一计算任意带宽 \(B'\) 的噪声：

\[
P_n(B')\,[\mathrm{dBm}]=-174+\mathrm{NF}+10\log_{10}B'.
\]

对于 UAV \(k\) 的子载波 \(s\)，其他 UAV 在同一子载波上的全部发射形成

\[
I_{k,s}^{\mathrm{cross}}=\sum_{k'\neq k}\sum_u x_{u,k',s}(\Pi)p_u h_{u,k}.
\]

设同一 UAV—子载波上的用户 \(i\) 和 \(j\) 满足 \(p_i h_{i,k}\ge p_jh_{j,k}\)，接收端先解码强用户 \(i\)，其 SINR 为

\[
\gamma_{i,k,s}=\frac{p_i h_{i,k}}
{p_jh_{j,k}+I_{k,s}^{\mathrm{cross}}+\sigma_s^2}.
\]

强用户被消除后，弱用户 \(j\) 的 SINR 为

\[
\gamma_{j,k,s}=\frac{p_j h_{j,k}}
{\varepsilon p_i h_{i,k}+I_{k,s}^{\mathrm{cross}}+\sigma_s^2},
\]

其中 \(\varepsilon\) 为 SIC 残余系数。每个用户速率按 \(R_i=B_s\log_2(1+\gamma_i)\) 计算，且强用户必须满足参数化硬约束 \(\gamma_{i,k,s}\ge\gamma_{\mathrm{SIC,min}}\)。主实验拟采用 0 dB 作为系统设计门限，并在 -3、0、3、5 dB 进行敏感性分析；该门限不被解释为信息论上的“正速率下界”。

### 4.3 并行部分卸载时延

任务 \(i\) 的卸载比例为 \(\alpha_i\in[0,1]\)，分配的 MEC CPU 为 \(f_i\)，结果数据量相对输入的比例为 \(\rho\)，相对时延预算为 \(T_i=d_i^{\mathrm{abs}}-a_i\)。本地分支与边缘分支并行执行，任务从到达时刻起计的处理时延定义为

\[
\tau_i=\max\left\{
\frac{(1-\alpha_i)C_i}{f_i^{\mathrm{local}}},\;
\alpha_i\left(\frac{(1+\rho)D_i}{R_i}+\frac{C_i}{f_i}\right)
\right\}.
\]

主指标仅统计唯一任务：

\[
\mathrm{OnTimeRate}=
\frac{\left|\left\{i:a_i+\tau_i\le d_i^{\mathrm{abs}}\right\}\right|}
{|\mathcal I_{\mathrm{arrived}}|}
=\frac{\left|\left\{i:\tau_i\le T_i\right\}\right|}
{|\mathcal I_{\mathrm{arrived}}|}.
\]

默认任务必须在到达时隙内满足 \(a_i+\tau_i\le d_i^{\mathrm{abs}}\)；未完成任务只记录一次 deadline miss，不得跨时隙重复进入分母。

### 4.4 联合优化目标与约束

令 \(z_i=\mathbb 1[a_i+\tau_i\le d_i^{\mathrm{abs}}]\in\{0,1\}\) 表示任务是否按时完成，研究目标为

\[
\max_{\Pi,\boldsymbol\alpha,\mathbf f}\ \sum_{i\in\mathcal I}z_i.
\]

主要约束包括：每个用户最多出现一次；每个 UAV—子载波最多两个用户；强弱角色与实际服务信道上的接收功率一致；所有 NOMA 对满足 SIC 门限；每架 UAV 的 CPU 分配满足

\[
\sum_{i:\operatorname{serving\_uav}_{\Pi}(i)=k}f_i\le F_k,\qquad \forall k\in\mathcal K;
\]

所有速率、时延和索引均为有限合法值。符号 \(a_i\) 仅表示任务到达时刻，服务归属统一由 \(\operatorname{serving\_uav}_{\Pi}(i)\) 或等价指示 \(x_{u_i,k,s}(\Pi)\) 表示。由于关联、子载波、配对和连续资源共同影响任务完成状态，直接全局求解成本较高，本课题采用可验证的分层方法处理。

## 5 研究目标与拟解决的关键问题

### 5.1 总体目标

建立面向全频复用多无人机 NOMA-MEC 网络的可信联合调度与资源分配方法，在明确系统假设和硬约束下最大化独立任务按时完成数，并形成可复现实验和论文证据链。

### 5.2 分目标

1. 建立显式任务、调度、分配和时隙结果数据结构，使服务归属只有一个权威来源。
2. 建立包含跨 UAV 同频干扰、SIC 残余及带宽一致噪声的统一物理层评价器。
3. 推导 deadline 驱动的最小卸载比例和最小 MEC CPU 需求，并证明最大基数资源选择规则。
4. 设计包含跨 UAV 服务迁移的确定性联合关联与配对邻域，以及满足硬约束的字典序搜索。
5. 建立固定外生轨迹、配对统计、canonical manifest 与图表自动生成流程。
6. 通过独立消融、机制实验、鲁棒性和完整枚举评价两个创新模块的贡献与适用边界。

## 6 两个拟创新点

### 6.1 创新点一：干扰外部性感知的跨 UAV 联合关联与配对

传统分层方案常先固定用户—UAV 关联，再在各 UAV 内独立配对，难以反映全频复用下一个关联动作对其他接收端的影响。本课题拟以显式 `Schedule` 为唯一决策对象，把用户、真实服务 UAV、子载波与 NOMA 角色绑定；任一候选动作后重新计算服务信道、强弱次序、SIC、跨 UAV 干扰和 MEC 候选集合。搜索采用三类确定性邻域：`Replace` 用未调度用户替换当前成员，`Position` 在同一 UAV 的不同子载波之间换位，`CrossUAV` 在不同 UAV 配对之间交换用户并同步改变真实服务归属。

候选解按“按时完成任务数、总 deadline slack、总跨 UAV 干扰、稳定调度编码”组成字典序目标，只接受严格改善，并在每次动作后检查唯一关联、容量、SIC 和索引合法性。可行调度集合有限且目标严格单调，因此搜索在所定义邻域内有限步终止。该创新的评价对象是**无线调度质量及其干扰机制**，将通过严格 2×2 邻域—接受准则消融、CrossUAV 负控制和真实交换事件日志独立验证。

### 6.2 创新点二：面向截止时间满足数的卸载与 MEC 算力分配

由本地分支约束 \((1-\alpha_i)C_i/f_i^{\mathrm{local}}\le T_i\)，得到最小卸载比例

\[
\alpha_i^{\min}=\max\left(0,1-\frac{T_if_i^{\mathrm{local}}}{C_i}\right).
\]

若 \(\alpha_i^{\min}=0\)，任务可完全本地按时完成，不占用无线与 MEC 资源。对必须卸载的任务，边缘分支满足 deadline 所需的最小 CPU 为

\[
f_i^{\min}=\frac{\alpha_i^{\min}C_i}
{T_i-\alpha_i^{\min}(1+\rho)D_i/R_i}.
\]

当速率非正、分母非正或需求超过 UAV 预算时，任务在当前调度下不可行。在可行定义域内，CPU 需求关于 \(\alpha_i\) 单调增加，因此 \(\alpha_i^{\min}\) 同时给出最小卸载比例与最小边缘资源需求。每个按时完成任务的收益均为 1，成本为 \(f_i^{\min}\)；对每架 UAV 将成本非降序排列并选取预算可容纳的最长前缀，即得到最大基数解。交换论证表明，若某解选入更高成本任务而排除更低成本任务，用后者替换前者不会增加成本或减少任务数，因此最长最小成本前缀的任务数最优。相同成本按 `task_id` 稳定排序，以确保复现。

该创新的评价对象是**给定无线调度后的任务完成数与 CPU 使用机制**，将通过同一 `Schedule` 下的固定比例、时延平衡点和 deadline-driven 三类分配器对照，以及数值搜索与完整子集枚举交叉验证。它不依赖创新点一即可独立成立，也可作为创新点一每次候选调度的精确下游评价器。

### 6.3 两个创新点的关系

创新点一输出物理与约束一致的 `Schedule` 及每个任务的无线速率；创新点二读取该调度，计算最小资源需求并在各 UAV CPU 预算内选择可完成任务。前者决定“谁由谁服务、在哪里复用、能获得何种速率”，后者决定“在这些速率下哪些任务值得获得 MEC 算力”。二者串联后共同优化端到端按时完成数，但使用不同消融和机制指标分别验证，避免把组合收益笼统归因于单一模块。

## 7 技术路线与算法流程

### 7.1 统一数据流

```text
固定外生轨迹（位置、任务、信道扰动）
  -> 最近 UAV 候选池与 per-UAV ILP 初始化
  -> 显式 Schedule
  -> Replace / Position / CrossUAV 候选生成
  -> 全量重算跨 UAV 干扰、NOMA 次序、SINR 与 SIC
  -> deadline-driven 最小资源需求与最大基数分配
  -> 字典序接受或结构化拒绝
  -> 统一任务评估器
  -> tasks.csv / slots.csv / events.jsonl / statistics.json
  -> canonical manifest、校验和与论文图表
```

### 7.2 初始化与搜索

初始化阶段按最近 UAV 形成候选池，枚举本 UAV 的可行用户对，排除明显违反 SIC 门限的候选，并在用户唯一使用和子载波容量约束下使用 per-UAV ILP 选择初始配置。求解器状态写入运行产物；求解失败时终止对应实验，不静默替换为其他算法。

局部搜索以稳定顺序遍历三类邻域。每个候选均经过调度不变量检查、全局物理重算和资源分配后形成四元字典序得分。主方法采用网络级 Global 接受准则；用于消融的 Bilateral 准则使用同一物理与资源模型，但要求受动作直接影响的每个配对局部效用均不下降且至少一个严格改善。严格控制其他条件后，才能判断跨 UAV 邻域和全局接受准则各自的贡献。

### 7.3 软件与证据架构

核心软件按领域结构、物理模型、调度约束、配对搜索、资源分配、仿真推进、实验入口、统计和产物管理分层。每个正式 run 保存 Git SHA、完整配置、seed、依赖与 solver 版本、平台信息、逐任务决策、逐时隙负载、交换事件和文件校验和。论文表格与图只能读取 canonical 结果生成，避免手工转录错误。

## 8 实验与统计设计

### 8.1 实验原则

所有算法读取同一 seed 预先生成的用户移动、任务到达、任务参数和随机信道扰动；算法结果不得改变未来外生输入。旧 seeds 42—61 只用于调试、探索和参数冻结，最终确认性实验使用 50 个未见 seeds 1000—1049，并在实现和参数冻结后一次性运行。旧版本结果不参与新方法性能证明。

### 8.3 指标与统计方法

主指标为唯一任务按时完成率。次指标包括 deadline miss 率、平均完成时延、用户级按时完成率向量的 Jain 公平性、CPU 利用率、不可行任务数以及 P50/P95 调度运行时间。每种方法在同一外生轨迹上形成配对样本，报告配对差值、10,000 次确定性配对 bootstrap 的 95% percentile 置信区间、双侧 Wilcoxon 符号秩检验、Holm step-down 多重比较校正与 rank-biserial 效应量[15-16]。若完整枚举未覆盖关联、配对、SIC 和资源分配的完整可行域，只能称为 restricted reference，不能称为 exact optimum。

## 10 风险分析与应对措施

1. **跨 UAV 搜索计算开销较高。** 通过确定性候选顺序、缓存可证明不变的量、早期拒绝非法候选和规模扩展实验控制复杂度；将 \(N=20\) 下 P95 调度时间低于 1 s 作为工程验收目标，而非当前已实现结论。
2. **SIC 门限与信道误差导致可行域收缩。** 将门限、NF、残余 SIC 和 CSI 误差纳入预注册敏感性实验，报告适用区间，不以单一参数点概括全部场景。
3. **创新点实证贡献不足。** 保持严格独立消融；若确认性区间不支持正贡献，回到邻域或接受准则设计，不通过筛 seed 恢复结论，并据证据调整论文声明。
4. **完整枚举规模快速增长。** 将 exact optimum 限定在小规模场景；大规模只报告运行时间、可行性和相对受控基线，不把受限枚举包装为全局最优。
5. **ILP 求解器或依赖环境不稳定。** 固化依赖和 solver 版本，记录求解状态；求解失败立即暴露，保留输入实例用于复现。
6. **论文数字与结果文件不一致。** 所有正式图表由 canonical JSON/CSV 自动生成，manifest 记录 Git SHA、配置和 seed，并用 SHA-256 校验产物。
7. **专业硕士工程落地性不足。** 除算法指标外，报告模块接口、异常原因、可重放事件和运行复杂度，形成可部署决策服务的接口原型与测试文档。

## 11 预期成果与验收方式

1. 形成干扰外部性感知的跨 UAV 联合关联与配对算法，输出显式、可验证的无线调度。
2. 形成 deadline-driven 卸载与 MEC CPU 分配算法，并给出解析推导、最大基数证明和数值交叉验证。
3. 形成配置驱动的多 UAV NOMA-MEC 仿真与实验软件，覆盖任务生成、统一评估、统计检验和 canonical 产物管理。
4. 形成严格 2×2 消融、资源分配消融、机制负控制、扩展性、鲁棒性和小规模最优性实验报告；所有结果由新 canonical 实验提供。
5. 完成专业硕士学位论文及开题、中期和毕业答辩材料，论文中的数字、图表和结论能够回溯到唯一 manifest。

最终验收重点包括：自动化测试通过；最终调度的 SIC、唯一关联、容量和 CPU 预算违规数为零；同 seed 科学数据可复现；两个创新点在独立消融中有清晰评价；完整算法与强受控基线比较表述准确；从干净环境能够重建实验、统计、图表和论文。以上均为计划验收条件，不构成当前性能声明。
